# 世界中心 NPC：制作障碍与“活人感”的外围证据

日期：2026-10-07。性质：定向调研与原件审读，不是穷尽查新、玩家研究或新方法提案。用户希望保留“以世界为核心，不以玩家为核心”的 NPC 方向；本报告不把它缩成作者成本问题，也不据此宣布世界中心一定优于玩家中心。

## 结论先行

**方向值得保留，但“更深的模拟 → 更像活人”不能当作已经成立的公式。** 开发者材料显示，成功作品在不同位置投入：独立生态、身份与关系延续、玩家可理解的反应、精心编排的人物活动。它们不是同一种技术的高低版本。

关于“作者最大的障碍”，本轮没有找到足以代表全行业并排出第一名的调查。能确认的是几个项目反复出现的实际障碍：行为内容的复用与修改、解释为什么某行为没有发生、把自主活动接进任务/动画/对白、在模拟预算与游戏节奏之间取舍。不能只归因为“作者还不会写聪明 policy”。

**对本项目的当前判断：保留世界中心的应用目标；尚未选出原创方法或经过证实的研究缺口。** 现有 Runtime 可用于以后检验，但本轮不改代码、不调 Dynamics、不跑新批次，也不把小场景 Praxish 的有界 NO_GO 扩成整个方向的否定。

## 2. 制作障碍具体发生在哪里？

| 障碍 | 一手案例 | 对我们应问的问题，而非已选解决方案 |
|---|---|---|
| 内容越做越难改 | A：旧 FSM 内容膨胀；GOAP 把动作条件/后果模块化，却仍有游戏专用耦合。B：行为图复制、复用和编辑流程问题 | 增加角色或条件，要改哪些定义？共享以后是否只是把分支搬进另一处？ |
| “没做”很难解释 | A：需要记录考虑过和排除的动作；最近目标剪枝曾导致折返路线。B：图的可读性和回归地图仍必要 | 不行动来自知识、候选、目标、规划、执行还是动画？作者能否定位？ |
| 自主系统进入内容链 | E：抽象任务仍需匹配人物、地点、对白/动画，并管理事件争抢注意力。G：Nemesis 依赖写作、配音、AI、动画、镜头等协作 | 少写一个响应分支后，其他制作环节是否反而更贵？ |
| 自主性会破坏游戏 | C：生态能制造难以通行的局面，要调整房间吸引度/地形。D/H：不同距离或规模采用不同模拟精度 | 哪些世界事实必须延续？哪些细节可以抽象？如何避免任务被永久破坏？ |
| “有生活”不等于“像这个人” | F：程序化营地活动尝试不能充分表现特定人物，转向人工编排。G：功能增生一度偏离个人宿敌的核心承诺 | 差异来自人物特性还是动作噪声？复杂机制是否让体验更难理解？ |

**推断**：成本不只在写行为，还在“定义 → 组合 → 接入游戏 → 解释失败 → 维护内容”。这是跨案例归纳，不是行业成本比例或瓶颈排名。作者定义类别与共享能力的想法仍有价值，但动作接口复用本身已经有先例；新贡献须落在可验证的额外能力上。

## 3. 有活人感的案例，究竟哪一层做得好？

下面的“体验线索”来自开发者设计意图，不冒称我们已测得玩家因果效应。

| 案例 | 已核实的做法 | 值得观察的体验线索 | 不能推断什么 |
|---|---|---|---|
| Rain World | 生物觅食、回巢、领地活动不只是玩家障碍；生态可发生在屏幕外。程序动画适应身体与地形 | 玩家进入的是既有竞争关系，而非为他开机的舞台 | 未核实离屏全精度、跨存档身份或预算；自主生态也可能使局面不可玩 |
| 原版 STALKER | 近处详细模拟，远处粗粒度；smart terrain 提供活动任务 | NPC 在玩家不注视时仍能换位置/活动 | 访谈中的自主搜神器/交易循环、弹药竞争包含**未上市原型**；不能混称最终系统都有 |
| Watch Dogs Legion | 被注意/互动的人物及关系进入更深持久层；背景路人可回收。已认识的人会被重用，记忆影响关系 | 再遇同一人，有可辨认的关系与过去 | 不是全伦敦每个路人永久全量模拟；部分态度理由是生成时回填，非全程因果生活史 |
| RDR2 | 部分营地人物活动采用精心手工编排，保持人物与叙事特点 | 不只“有人在忙”，而是“这个人正在这样生活” | 不能据此说整部游戏没有系统模拟，也不能用总开发人数估 NPC 制作成本 |
| Nemesis | 以个人宿敌和玩家故事为核心，系统、表演与人物区分配合；测试后收缩过度复杂功能 | 经历成为可记住的人物关系 | 它明显围绕玩家，恰是“只有世界中心才能活起来”的反例；本轮未审读详细算法 |
| KCD2 | 官方 2025 摘要描述 MBT 目标状态配 GOAP；2026 摘要另述数千 NPC 的 LOD | 可作为下一轮生活活动与规模管理的原件 | 摘要不是作者成本、玩家可置信性或完整离屏连续性的验证 |

**关键修正**：并不存在一条从脚本、utility、GOAP 到 LLM、再到深心理模型的“活人感升级阶梯”。同样可见的生活，可能来自生态规则、持久关系、调度与内容组合，也可能来自认真编排；需要分别追溯，而不是只给成品贴“聪明 AI”的标签。

## 4. 玩家到底会读什么？新增论文提供的有限答案

P 的实验 1 有 102 名玩家观看四种无声短视频，操纵士兵/平民外观与攻击/投降是否符合预期；实验 2 有 91 名 Ubisoft 员工体验一致、反向但一致、混合不一致的规则。它研究的是射击场景中外观—行为的协调与跨遭遇规则稳定，不是 NPC 独立日常生活。

结果支持：协调性影响若干可置信性/智能感题项；稳定的反向规则可以被学习，混合规则降低部分行动确信。意外行为并非所有维度都变差，部分人格/注意反应评分可上升；不能得出“永远可预测最好”。

限制：单类型游戏与偏向特定玩家的样本；没有比较模拟深度、作者成本或 LLM；未复核原数据/脚本，重复测量的分析表达尚需进一步核对。因此不能把论文题项直接做成通用 NPC 分数。

**项目推断**：玩家不仅看动作多不多，还会根据角色外观/身份、情境和此前经历解释行为。连续性需要可辨认的线索；但“世界在玩家之外运行”是否本身提升体验，仍需另外验证。WebGPT 提出的五类活人感可作观察提纲，不是已验证五因子量表。

## 6. 对本项目意味着什么，以及尚未回答什么

**已确认的用户方向**：世界中心；玩家可以加入、干扰，但不是所有活动存在的理由。作者设定身份、目标和游戏约束并非缺点，要减少的是新情况只能靠专用补丁处理的负担。两者保持并列，不把作者效率取代体验目标。

**实现观察**：现有 W/O、Runtime、动作校验与 trace 是执行基座；它们并未提供经玩家验证的行为方法。本轮未修改 Runtime、Dynamics、policy、schema 或已有实验产物；未提交的 paired 探针亦不纳入验收。

由上述证据得到的三个**待定位窗口**，不是已发现的创新：

1. 自己的活动在环境变化下如何组合、恢复/放弃，同时保留作者约束？既有 GOAP/BT/活动系统是否已足够，缺的是工具还是机制？
2. 世界在不同模拟精度间如何保持有意义的身份/活动/后果连续性？哪些事实需要真算，哪些只需要一致？
3. 已经真实发生的目标、知识和经历，如何用动作/环境/表演让玩家看懂，而非靠语言润色制造聪明错觉？

目前不能确认其中哪个是我们的首个论文问题。也没有证据要求先训练完整 policy、先拟合心理学参数或替换成熟规划器；不做这些并不等于永远不做训练。

### 唯一下一动作

**先交付这份对照，与用户讨论要保留哪种世界/人物连续性，再选一组生产原件作更深机制拆解。** 暂不启动新 demo/批次。优先候选是 STALKER 与 Legion 的“远处/未关注人物如何延续”，因为它能直接澄清世界中心并不等于全量全精度，但是否选择由讨论决定；此推荐不是自动开工授权。
