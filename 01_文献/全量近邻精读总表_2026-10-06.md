## 结论先行

**已被近邻覆盖的不是某个一模一样的 Paper-0 实验，而是一系列过宽的新颖性说法。** 长程行为链预测、动态 persona、多状态轨迹、虚拟世界中角色 belief/state 更新、角色一致性评测，以及“紧凑状态应对未来可观察结果保留预测信息”，分别已有直接先例。因此不能单独主张“动态角色状态”“长期行为预测”“局部知识边界”“持续情境演化”或“预测充分状态”是新的。

Paper-0 仍可作为一个**待验证且可失败的实验问题**：固定角色合法可见信息 `O`、`P` 与有限候选支持集 `A^O`，用独立于被测系统的下一动作 `A*`，按 user/session/角色留出，比较显式持久 `S`、完整/结构化历史、强摘要、无状态/容量匹配朴素状态与置换 `S` 的 held-out action NLL、成本及必要消融。这里“尚未由本轮读到的论文完成同一估计目标”只是限定本轮比较范围，**不是穷尽查新后确认的新颖性**。

## 深读与方法谱系

### 1. SyncStream：预测误差驱动的流式 prototype 维护，不是心理漂移

**准确书目**：Junming Shao, Zahra Ahmadi, Stefan Kramer, “Prototype-based Learning on Concept-Drifting Data Streams,” KDD 2014, pp. 412–421, DOI [10.1145/2623330.2623609](https://doi.org/10.1145/2623330.2623609)（ACM DOI 为规范出版入口；本地 PDF 首页与 DOI 核对一致）。本地：[2014_SyncStream PDF](PDF/2014_SyncStream_Prototype_based_Learning_on_Concept_Drifting_Data_Streams.pdf)，10 PDF 页。**阅读等级：Codex/Luna 代理全文审读，主代理方法/证据复核。**

| 项目 | 核查 |
|---|---|
| 训练信号 | 连续到达样例的真实类别 `y`。对 prototype 预测后取得真标签；其 `Rep` 初值为 1，预测正确 +1、错误 −1。不是自监督，也不是心理状态标签。 |
| 方法链（原文位置） | §3.1/3.5，PDF pp.2、6：P-Tree 最近 prototype 最近邻给类别预测。§3.2，pp.3–4：ε 邻域内同类特征向量以同步振子更新相位，异类样例为 cannot-link；局部 order parameter 收敛，同相样例成为 prototypes；谱系引用 Böhm et al., “Clustering by Synchronization,” KDD 2010, DOI [10.1145/1835804.1835879](https://doi.org/10.1145/1835804.1835879)。§3.3.1：按类别比较相邻块协方差主方向最大夹角，实验阈值 60°。§3.3.2：按类/特征维度做秩统计并扩展 Brunner–Munzel 检验，以最小 p 值表示变化，实验阈值 p≤.01。§3.4/Algorithm 1，pp.5–6：P-Tree 当前 prototype 层 + 历史 concept 层；容量触发后删除低 representativeness 项（正文举负 `Rep` 为例），将 `Rep` 未变化项重新聚类，其余高代表性项保留；`maxC` 满时删最旧 concept。突变时归档当前层并清空，周期性摘要时不清空。chunk size、周期 `T`、`maxP/maxC` 控制检测与预算。 |
| 数据/评估/对照 | 两条各 1,000,000 样例的 synthetic moving-hyperplane stream；Spam 9,324、Electricity 45,312、Covtype 581,012、Sensor 2,219,803 样例。与 Adaptive Hoeffding Tree、IBLStreams、Weighted Ensemble、OzaBagAdwin、PASC 比较 Accuracy/Precision/Recall/F1 与处理时间；报告渐变/突变流和 `maxP`/chunk-size 敏感性。论文没有逐一移除 `Rep`、同步聚类、P-Tree 的完整组件消融。 |
| 可继承 / 不可外推 | 可实现一个独立预测记忆 baseline：历史可见片段以外部 `A*` 标注，预测错误更新 prototype 保留分数，受预算约束压缩，再在 user/session holdout 比较压缩前后的 NLL。必须补上同容量摘要、raw history、no-S、permuted-S 和模块消融。不能把 `Rep` 称作心理重要性，把统计漂移称作心理漂移，也不能把原型库说成可解释的持续心理状态。复现注意：§3.4 文字称容量超过预算时处理，而 Algorithm 1 检查 `== maxP`；`getNegativePrototypes` / `getUnchangedPrototypes` 的精确分界未展开，应查作者代码而非擅自补规则。 |

**项目含义**：SyncStream 对“该怎样监督选择和压缩有预测价值的历史”提供了具体可实现的比较算法；它没有提供情绪、人格、动机或状态转移模型。概念漂移的对象是数据流中的 `P(Y|X)`/类别条件几何，不是某一角色的心理演变。振子方程是特征聚类的同步更新，不是情绪振荡机制。所有关于角色预测的继承，均须以独立 `A*` 和外部留出集重新验证。

### 2. EMA：因果解释—appraisal—coping 的过程模型

**准确书目**：Stacy C. Marsella & Jonathan Gratch, “EMA: A Process Model of Appraisal Dynamics,” *Cognitive Systems Research* 10(1), 2009, pp.70–90, DOI [10.1016/j.cogsys.2008.03.005](https://www.sciencedirect.com/science/article/pii/S1389041708000314)。本地：[2009_EMA PDF](PDF/2009_EMA_Process_Model_of_Appraisal_Dynamics.pdf)，21 PDF 页。**阅读等级：Codex/Luna 代理全文审读，主代理方法/证据复核。**

| 项目 | 核查 |
|---|---|
| 训练信号 | 本文不是监督训练论文；因果解释、事件、命题、目标/计划与 coping 规则由建模者编码。文中提到的先前慢演化情境人类自陈工作并不等于本篇鸟事件的独立验证。 |
| 方法与证据位置 | §2.3.1–2.3.3，PDF pp.8–10 / 印刷 pp.78–80：以 causal interpretation 表示过去事件、当前世界命题、可能后果及计划，命题可附 belief/utility/probability；appraisal detectors 读表示但不直接改写它。§2.3.3：并行评 relevance、valence/intensity、likelihood、expectedness、causal attribution、goal conduciveness、urgency、control/power、norms。§2.3.5 / 印刷 pp.82–83：coping 可改 belief/desire/intention/plan/attention，继而重评。§3–4 / 印刷 pp.83–89：用实验室鸽子意外飞入、演员约 2.6 秒反应作解释性模拟。 |
| 评估与局限 | 是对一个自然事件的解释性模型演示，不是演员真实情绪/推理的确认；作者要求更受控实验以区分模型假设。§2.3.1 注 3：模型假设过去/现在命题可观测，与项目 `O` 可能 stale/unknown 的局部可见性相冲突；作者也指出编码主观性、时程参数浅/部分自由、复杂交互过程难证伪。 |
| 可继承 / 不可外推 | 真正继承需要保留“观测/推断改变因果解释→appraisal 读解释→coping 选择性改 belief/goal/intention/attention→动作与反馈再评价”的过程分层，并显式表示来源、时间、不确定性及可干预条件。仅给 `fatigue` 等字段取心理学名字、套固定衰减率或计算情绪标签，不是继承 EMA；EMA 也未验证项目四个字段或常数。 |

### 3. FAtiMA-PSI：需求/经验学习进入目标效用与意图切换

**准确书目**：Mei Yii Lim, João Dias, Ruth Aylett & Ana Paiva, “Creating Adaptive Affective Autonomous NPCs,” *Autonomous Agents and Multi-Agent Systems* 24(2), 2012, pp.287–311, DOI [10.1007/s10458-010-9161-2](https://doi.org/10.1007/s10458-010-9161-2)；作者机构记录：[Heriot-Watt Research Portal](https://researchportal.hw.ac.uk/en/publications/creating-adaptive-affective-autonomous-npcs/)。本地：[2012_FAtiMA PDF](PDF/2012_FAtiMA_Creating_Adaptive_Affective_Autonomous_NPCs.pdf)，31 PDF 页。**阅读等级：Codex/Luna 代理全文审读，主代理方法/证据复核。**

| 项目 | 核查 |
|---|---|
| 训练/反馈信号 | 没有外部下一动作 gold 训练。特定角色对具体 goal 的试做成功/失败记录估计成功概率；观察到的目标结果与预期误差更新 uncertainty，属于系统交互反馈。 |
| 方法与证据位置 | §4.1，PDF pp.7–14：旧 FAtiMA 的快速 OCC 事件规则与 deliberative intention appraisal/BDI 规划；作者指出大量手写 desirability、目标、动作倾向、阈值与 decay 不易校准。§4.2，pp.15–24（特别 pp.19–22）：PSI homeostatic drives；`Uncertainty_t(g)=α·ObservedError_t(g)+(1−α)·Uncertainty_{t−1}(g)`；competence 由成功/失败概率差更新；goal utility 汇总对多个 drives 的作用并结合 expected competence/urgency；selection threshold 控制切换 intention，避免来回切换。 |
| 评估与局限 | §5，pp.24–27：meal/recycling/gardening ORIENT 场景运行示例与青少年游戏体验研究（英国/德国各 4 组、每组 3 人）。作者 p.27 明言没有与 FAtiMA/PSI 的技术比较（如 authoring cost 或行为改进），难以孤立性能差异。参与者感觉角色有趣可信，不是独立下一动作预测或算法消融。 |
| 可继承 / 不可外推 | 可把“由真实 outcome 更新 goal-specific 成功概率/不确定性→驱动缺口与情境共同影响 goal utility→显式 threshold/commitment 选择 intention”实现为可检验 NPC baseline；需要具体 goals、outcomes、尝试记录、概率预测与相同候选动作对照。只套一个 EMA 更新式到 `satisfaction`，不构成 FAtiMA-PSI。不能声称本文验证了 ResearchDynamicsV1 的字段、速率或动作预测。 |

## 方法基座与定向精读边界

### 11. HSSA：Hierarchical State Space Affective Dynamics

**准确书目**：Tom Lodewyckx, Francis Tuerlinckx, Peter Kuppens, Nicholas B. 方法边界：论文拟合的是 HR/BP 对应的连续生理状态及其个体差异参数，不是心理人格或动作策略；分层先验不等于已识别的人格 `P`。它可作为连续状态动力学与层级参数估计的方法参考，不能直接支持本项目的心理 `S`、离散动作预测或 Paper-0 必要性。该方法迁移仍受观测定义、过滤/平滑、参数恢复和前向预测准入约束。

## 近邻覆盖与 Paper-0 新颖性边界

| 近邻 | 已覆盖 / 与项目可能重叠 | 不能据此主张 / 尚未等同 |
|---|---|---|
| Generative Agents | 记忆检索、反思、计划、观察驱动的角色闭环与组件消融 | 不是独立真实动作预测、状态必要性或心理因果效应 |
| BehaviorChain | persona + history + context 的连续下一行为推断及历史消融 | 文学/传记叙述行为、生成 judge 分数不等于局部可见角色的独立真实 `A*`；benchmark 选择也非校准动作概率 |
| CharacterBox | 文本虚拟世界、角色状态/belief/memory 更新、行为轨迹和一致性评价 | sandbox 生成轨迹与 judge fidelity 不能证明真实下一行动预测或显式 `S` 的必要性 |
| DYNToM | belief/emotion/intention/action 随故事变化的动态轨迹评测 | QA benchmark 不是状态更新算法或测量到的人类心理因果过程 |
| Dynamic Persona Coherence | 稳定 identity + 累积 adaptive state、短中长时尺度、状态消融和闭环纠偏 | 合成 persona/事件与 LLM critic 不能验证真实心理状态或真实人类动作预测 |
| PSR | 由历史更新、面向未来可观察结果的预测状态思想 | 一般动力系统理论不等于心理理论；不替项目设计行为 test 或独立数据 |

因此，“动态状态 + 角色一致性”“history 到连续行为”“局部观察与信念”“预测状态”“带情绪的长程 persona”都不能单独作为本项目创新点。只能把 Paper-0 的明确实验组合保留为**待检验目标**，同时继续查新，不预先宣称 gap。

## 项目决策边界与后续准入

1. 本次文献审计未修改状态机、字段、系数或协议，也未运行训练/实验；这是本轮审计范围事实。[`Research_Dynamics_V1_Protocol`](../00_研究设计/Research_Dynamics_V1_Protocol.md) 仍标注为候选未冻结，四个字段与常数未被上述论文校准。
2. SyncStream 值得作为预测记忆压缩对照算法研究，但只在候选真值独立、容量和支持集匹配、角色/session 留出、报告 NLL 与消融后，才能回答它对 Paper-0 有何价值。
3. EMA/FAtiMA/PsychSim 可以分别提供过程、目标适应和 belief-decision 机制参照；不得将各自构念/规则拼接成一个未经验证的“宏大新模型”。先保留作为对照或后续候选机制，并要求输入、状态写入、观察权限、结果信号逐项操作化。
4. Source-observed action labels 不自动等于现实人的 gold `A*`；正式 Paper-0 证据仍需满足问题卡的独立 `A*`、冻结有限 `A^O`、合法 `H^obs`/无未来泄漏、user/session/episode split 与预注册 NLL/等价界要求。E0 自生成行为不是外部真值。PredictionBaselineV1 的实现/训练当前状态与执行协议见[研究重建审计](../00_研究设计/研究重建审计_2026-10-06.md)和[开发协议](../02_实验/PredictionBaselineV1/README.md)，文献总表不重复维护实时授权或运行状态。
