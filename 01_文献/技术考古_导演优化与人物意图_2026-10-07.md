## 1. DODM：不是“最少干预”的免费证明

**E：**Nelson、Roberts、Isbell、Mateas，*Reinforcement Learning for Declarative Optimization-Based Drama Management*，[AAMAS 2006 作者原件](https://www.kmjn.org/publications/DODM_AAMAS06.pdf)，pp.775–782；Luna 阅读正文方法/实验/结论，主代理复核 §1/3 与 precedence matrix。另读 Nelson、Ashmore、Mateas 的 [*Authoring an Interactive Narrative with Declarative Optimization-Based Drama Management*](https://ojs.aaai.org/index.php/AIIDE/article/download/18761/18537/22440)，AIIDE 2006，pp.127–129，3 页 authoring poster；不要把不同作者/版本揉成一篇。

| 十字段 | DODM 的实际对象 |
|---|---|
| 控制问题 | 在玩家不确定选择下，用 DM actions 优化作者规定的全局故事质量 |
| 保存对象 | 已发生 plot points 的有序历史、DM action history、前置约束及点/动作 annotations |
| 输入→输出 | plot points、DM action library、story evaluation function → 当前 DM action 或 null |
| 触发 | plot-point progression 的抽象决策；不模拟每个游戏低层动作 |
| 搜索/评分 | SAS+ expectimax 或 TD value network；作者 weighted feature score，非单独最少 intervention 保证 |
| 作者工作 | plot point recognizer、前置/可用条件、feature/权重、DM action 的低层 refiner；选 RL 也要专业知识 |
| LLM 可补（I） | 从高层 hint/cause 提议现成动作序列或辅助写 refiner；此处是否省总劳动尚未测 |
| 可吸收（D） | DM action taxonomy、null action、操控成本 feature、simulated player 与 manager 分离 |
| 与项目冲突 | deny/直接 cause 可能幕后改 W 或 override agent；必须按具体权限分条件，不称全部 world-only |
| 比较候选 | null DM、SAS+、TD；同 domain/action library/evaluator/player；用户成本另记 |

`(action, plot point)` 的五类 action：cause 使点立即发生，deny 令其本次不可达，temporarily deny 暂时封闭，reenable 解封，hint 提高玩家遇到该点的概率。它们有合法性与作者 plausibility 条件；refiner 是否能真正实现仍是工程负担。

**SAS+：**DM maximizing node 与玩家 expectation node 交替，有限深度 full-width 展开；cutoff 后采样合法后续 plot sequences，平均终局 evaluation 作 leaf value。采样前解封 temporary-denied 点，之后采样阶段不再由 DM 操作。**TD：**神经网络近似部分历史到终局评分的期望，不是学 NPC 动作心理。SASCE 使用同一 V 给合作/对抗模拟玩家选择分布，混合比例和 hint 偏置改变训练探索；这些概率不是实测真人玩家。

状态的 `M[i,j]=1` 表示 **i 发生在 j 后面**。原例 `3→4→2` 的非零项是 `M[2,3]、M[2,4]、M[4,3]`；不能反读。value network 编码全局顺序，不只上一步动作。

**E：The Guilty poster 的 authoring bottleneck。**作者标注 plot points 揭露的背景信息、写 acceptable ordering/coherence、定义 backstory fixedness 的 ideal arc，再把实际 fixedness 对齐该 arc 评分；另有渐进披露、错误怀疑反转和背景 tone 等偏好。manipulativeness 是可标在 DM action 上的 soft cost，不是自动测到的玩家感受。NWN 的“较笨”角色还需直接修改 dialogue tree；recognizer/refiner、物品配置与模型不是消失了。作者报告全局改目标比局部 triggers 更易调，**没有计时/受控成本对照**。因此“点+线+干预成本”已有直接祖先；“LLM 会把总劳动降几个数量级”仍是待检验假设。

大域实验还显示 action library 不充分时各种 optimizer 都表现差，加入 synthetic DM operators 才改善。搜索更强不自动修复 domain 不足；若新增算子才救活结果，要记 authoring cost，而非只报 planner gain。

## 2. IDA（方法来源 2004，不倒灌 2003）

**E：**Magerko、Laird，[*Mediating the Tension between Plot and Interaction*](https://cdn.aaai.org/Workshops/2004/WS-04-04/WS04-04-022.pdf)，AAAI workshop 2004，pp.108–112，委派全文。2003 TIDSE 只核实书目，未取得全文。

输入为已写剧情点、前后条件、DAG/相对时间及规则型玩家模型；保存 world snapshot 与当前剧情点。触发是预测玩家将违背未来节点/窗口，复制世界并用玩家模型 rollout；导演查相应纠正动作，可改角色 goal/info/原子行为、生理量或世界对象/声光。作者仍需节点、玩家模型、纠正库和合法域；当预测错时不能当真实人物意图。可借 **提前识别 impending violation** 与不修改真实 W 的预测支路；不能把源论文的广泛写权限暗缩成纯 world opportunity steering。本轮没有该系统的玩家预测效度/源码复现。

## 3. Disney 两层 online planning（2018）：curve 不是真时钟

**E：**[*A Two-Level Planning Framework for Mixed Reality Interactive Narratives with User Engagement*](https://la.disneyresearch.com/publication/a-two-level-planning-framework-for-mixed-reality-interactive-narratives-with-user-engagement/)，AIVR 2018，pp.100–107；[作者 PDF](https://studios.disneyresearch.com/app/uploads/2019/03/A-Two-Level-Planning-Framework-for-Mixed-Reality-Interactive-Narratives-with-User-Engagement.pdf)。Luna 定向阅读 §III–VIII，主代理核验 story arc invariants/trajectory/MCTS；不是现实 engagement 模型已获玩家验证。

| 十字段 | 两层机制 |
|---|---|
| 控制问题 | 作者 story graph 中选较参与感的路线，并在线落成智能对象事件 |
| 保存对象 | physical/story/experience state；smart-object events；各 arc 的 preconditions、invariants 和 endpoints |
| 输入→输出 | authored graph+W+用户 engagement proxy → arc path，再 event plan |
| 触发 | 初始化/arc 转换/玩家改变条件；执行下一 event 时规划后续 |
| 搜索/评分 | 上层穷举无环 story paths，以每 arc engagement 序列选路径；下层 UCT/MCTS 搜索 event instances 到所选目标 |
| 作者工作 | arc graph、目标/不变量、events/真实效果、失败退出/可逆路线、engagement feature |
| LLM 可补（I） | 事件候选/refinement，不使有限预算 search 成为可达性证明 |
| 可吸收（D） | storyline/低层执行分开；玩家破坏 arc invariant 后离开原 arc；执行一步再计划 |
| 与项目冲突 | system 控事件序列不等于各 NPC 自主 policy；用户变化不是等待 action 全做完后补发 |
| 比较候选 | 固定 arc/no engagement、trajectory-only、两层规划；玩家体验需另验证 |

下层按 UCT exploitation/exploration 选择，展开合法 events、有限随机 rollout、对二进制 mask 下目标距离打分并回传 visit/value；权重来自上层 engagement 分数。案例使用约 1500 ms 规划预算，没找到路径只能记 budget failure，不能称数学无解。

**E：**当前 ideal trajectory 恒为 1；候选序列每个 **story arc 一个值**，按平均 engagement 选高值路径。limitations 明说当前不考虑 temporal aspect；不是本项目 scheduler elapsed-time 上的心理曲线。把它推广到多条时间趋势是新任务，不是论文已经验证的功能。

## 4. IPOCL：已有意图解释，不重复假装新发现

**E（继承此前核读，不计本轮新全文）：**IPOCL 2004/2010 的原件与阅读账本在[Author Goals 审计](调研子审计_AuthorGoals与叙事规划_2026-10-07.md)及[原算法拆解 §2.6](算法拆解_NPC方法与生产系统_2026-10-07.md)。

输入是 domain/initial state/作者 goal；保存 plan steps、因果链接和 **frame of commitment**（actor、internal goal、实现 steps、区间及 motivating step）。refinement 不只解决 open conditions/threats，还处理 motivation/intent flaws，让计划中的人物行为归入被激发的角色目标。作者仍定义动作 effects 与 motivates 语义；不能读一段剧情就发现真实心理。

可吸收的是“动作合法之外，还追问它支持谁的 goal、该 goal 何时被什么激发”；拟合/目标识别/actor-local O 是另外接口。其受限符号规划及目标完成假设不等于可持续允许失败的开放世界人物。比较时 causal-only POP 与 intentional planning 是合理控制；不能拿手写 personality law 加一层文字理由代替 IPOCL。

## 5. Thespian + POP（2008）：最值得借的人工缺口

**E：**Si、Marsella、Riedl，[*Integrating Story-Centric and Character-Centric Processes for Authoring Interactive Drama*](https://ojs.aaai.org/index.php/AIIDE/article/view/18698)，AIIDE 2008，pp.203–208；[PDF](https://cdn.aaai.org/ojs/18698/18698-52-22313-1-10-20210927.pdf)。Luna 全文；主代理复核 pp.204–207、Algorithm 5 与两个示例。

| 十字段 | 真实机制 |
|---|---|
| 控制问题 | 抽象 POP 大事件可因果合法，却不让细粒度人物模型愿意执行 |
| 保存对象 | plot skeleton、Thespian/PsychSim states/action dynamics/reward goals/beliefs/有限 lookahead policy |
| 输入→输出 | plot anchors+角色模型 → 可 fit 的完整 story path；失败时 belief-change suggestions |
| 触发 | 逐步拟合 plan prefix，找到首个无法 fit 的 gap |
| 搜索/评分 | 按作者优先 action sets（small talk→其他两侧角色动作→别的角色）递归枚举至 maxLength；保留锚点顺序/完整性，再检 fit；不是统一最小改变目标 |
| 作者工作 | 两层 domain、goal rewards/weights、动作动态、搜索优先级；缺少行动时新增具体动作与效果 |
| LLM 可补（I） | 把“需要什么 belief effect”转成多种可执行事件提案；仍要审核 permission/状态支持/模型效果 |
| 可吸收（D） | 区分 skeleton、已有 action bridge、missing effect、author-approved new operator；fit 回馈不冒充人物体验 |
| 与项目冲突 | fitting 会调角色 motivation weights；不能把它藏在 Runtime 或说角色设定永不被改；源码 belief model 不是我们的真实 O |
| 比较候选 | 原 action search vs 加 proposal assistance；须分开 library 增补与搜索收益，计作者补修劳动 |

**E：**总览 p.204 确实以“木匠告诉 Red 狼可信”举作者发明动作的例子；formal Example 1 是 small talk 建立 rapport，Example 2 是进屋前建议 Red 相信屋内是外婆/狼在别处/狼吃饱等，然后作者加入伪装、假装离开或吃食物动作。不要把总览示例冒充已展示的完整运行。

Algorithm 5 先模拟到 gap，调用 `Suggest_Pick(actor,next_action)` 给需要的 belief change；也枚举他人的回应，用一步 lookahead 检查哪些预期回应可使 actor 选下个锚点，再对另一角色提出 belief change。**系统只指出效果，作者仍发明事件**。全系统只用于一个 Red Riding Hood；各 gap 独立填，前一个修补可损害后一个，作者在例子里主动拒绝“狼先离屋”。这正是局部可 fit 不等于整条剧情可行的反例。

**Q：**2008 论文假设标准 POP，fit/suggest 的内部权重优化依赖此前 Thespian/PsychSim 工作。本轮没有展开那些求解器源码或证明其完备性；已吸收的是该文 gap 搜索与作者交互接口，不称已经取得全部拟合程序。

## 6. SPG / Intention Dependency Graph（2017）

**E：**Amos-Binks、Potts、Young，[*Planning Graphs for Efficient Generation of Desirable Narrative Trajectories*](https://ojs.aaai.org/index.php/AIIDE/article/view/12989)，AIIDE-17 workshop，pp.146–153；[PDF](https://cdn.aaai.org/ojs/12989/12989-52-16506-1-2-20201228.pdf)。不是 2013 同名 dialogue IDG。Luna 全文；主代理复核 Jaccard 和 Assessment/limitations。

| 十字段 | 实际机制 |
|---|---|
| 控制问题 | 用户偏离后想比较多种有不同角色目标依赖的未来，而非昂贵地枚举全部完整 plans |
| 保存对象 | Φ=(I,G,C,S,Λ)、literal/action layers 的 SPG、character-goal graphs、带目标集合 labels 的有向分层 IDG |
| 输入→输出 | 有动作 schema/motivations 的 narrative domain → exemplar goal conjunctions 的估计集合 |
| 触发 | 规划/重规划时构图；不是已给出完备 runtime accommodation selector |
| 搜索/评分 | 在 SPG reachable layers 传播 intentional/motivational histories；新依赖创建 IDG nodes/edges；终层 labels 比较 Jaccard |
| 作者工作 | action pre/effects、character goal/motivation 支持、原 reference exemplar |
| LLM 可补（I） | 候选目标/事件，但不能把模型猜出的 goal 当已验证 persistent state |
| 可吸收（D） | 相同目标/不同动作与不同目标/相同动作要区分；goal set distance 作为解释性 baseline feature |
| 与项目冲突 | relaxed graph reachable ≠ W executable；目标最少变化 ≠ 玩家觉得连续；非必要日常活动会被排除 |
| 比较候选 | 原 goal-set distance、动作/历史保持等分项比较；不先揉成新心理 objective |

`character goal=(character,literal)`；intentional paths 为某个被 motivated 的 goal 提供支持，允许其他路径满足其余 preconditions。IDG vertex label 保存所需 goals 的合取，dependency edges 来自 action 的 intentional/motivational 支持，不是 LLM 画的语义相似图。

原示例比较 `d(A,B)=1−|A∩B|/|A∪B|`：`v4→v8 = 1−3/4=.25`，`v4→v7 = 1−2/6≈.667`（原文记作 .66），对象是 **labels 中的 character-goal 集合**，不是动作/世界/情绪向量。若按“目标改得少”选择则偏向 v8；不等于原文已实现且证明全局最优 repair。

**E：limitations**：SPG 无 mutex，可高估实际可达 exemplars；在达到 G 时停止，漏更长但目标依赖不同的解；仅包括达目标必要 goals，可能漏有叙事意义的 dead-end 日常支路。Jaccard 不能覆盖全部叙事差异，指标效度/经验评估是后续工作。可作为 baseline 表征，不能拿它自动验收“人没突然换脑子”。

## 7. 这几种机制怎么一起手推，而不是混成一个算法

沿用[钥匙被毁例](技术考古_叙事中介与未来修复_2026-10-07.md#5-手推一个真的-causal-link-exception)：

1. Mediation 先指认 `has_key → unlock` 哪条边断了，不因所有偏离都修。
2. Thespian 式问题再问 caretaker 的现有目标是否支持借钥匙；若不支持，先搜已建模互动，不直接设 `trust+=0.2`。
3. LLM 可以提“提供还债证明/共同熟人作担保/交换资源”，但须当前世界真有对应资源/人物/信息，且 actor 可获得。没有 operator 时标为**域扩展提案**，不能伪装为原动作库找到 bridge。
4. IPOCL 式检查为借钥匙标明动机与目标支持。IDG 式比较修复前后 goal labels，但 Jaccard 小不允许跳过可执行性。
5. DODM 式比较候选干预及 null 的叙事 feature/cost；作者的权重、认知操控感与真实玩家评价必须分开。

**D：**这是一张可借机制的分工图，不是完成的现代 NPC 方法。动作域与动机 law 如果由同一 LLM 随提案改写，再按改写后的模型验证，会把错误搬到 model acquisition；接法和作者劳动账见[总报告](专题调研_多粒度剧情连接与LLM重组_2026-10-07.md)。
