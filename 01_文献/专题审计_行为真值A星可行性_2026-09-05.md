# 行为真值 `A*` 可行性审计

审计日期：2026-09-05  
范围：只判断现有近邻资源能否提供**独立于本项目规则模拟器**的下一行为目标 `A*`。不下载数据集、不训练模型、不把任何候选提前写成研究结论。

## 要解决的缺口

项目的 Replay 协议要求：在时刻 `t`，系统仅据 persona、历史和角色可知信息输出 `π(A_t)`；随后才揭晓外部记录的真实动作 `A*_t`，用概率、排名或 NLL 评分。

当前 C++ reference demo 的动作由同一套 `X/S/D/π` 规则采样。因此它能验收日志、候选集、世界结算和干预接口，却**不能**充当该协议中的独立 `A*`：用它评估只是在测规则复现自身。

本页的四个准入条件：

1. **连续性**：有可排序的多步行为而非孤立问答；
2. **目标可定义**：能在预测时点取到一个之后才揭晓的动作目标；
3. **信息边界**：能声明角色当时可知什么，或诚实标注无法恢复；
4. **可获得与可复现**：数据/导出路径、许可证和切分方式可核验。

## 审计结论

| 候选 | 连续行为 / `A*` | `W/O` 信息边界 | 获取情况（2026-09-05） | 判定 |
|---|---|---|---|---|
| BehaviorChain | 有：每 persona 10–20 个 context–behavior 节点；其 MC 任务含一个正确行为 + 3 distractors | 未提供可直接复用的显式角色信息遮罩；context 是叙事整理物 | **完整数据暂扣**，官方仓库要求邮件联系，理由为版权 clearance | 不可作当前可运行数据源 |

## 逐项证据与边界

### BehaviorChain：任务最像，但数据当前不可用

[论文](https://aclanthology.org/2025.findings-acl.813/)定义 persona profile、history、连续 context–behavior pairs；每条链长 10–20，multiple-choice 输入中正确行为配三个干扰项。这满足连续性和一个有限候选的 `A*` 形式。

但论文资源链接指向的[官方仓库](https://github.com/O-L1RU1/BehaviorChain)当前明确写明：完整数据因版权问题暂不公开，需联系作者；公开的是抽取与评测 pipeline。因此不能以“论文已发表”误记为“数据可直接复现实验”。即便未来取得数据，也仍须补做叙事 context 到 `O` 的可知性标注；它原始协议不是 `W ≠ O` 评测。

### CharacterBox：可读的世界资产，不是独立行为真值

[CharacterBox 论文](https://aclanthology.org/2025.naacl-long.323/)把行为轨迹作为 LLM role-playing 的评价/增强环境；[官方仓库](https://github.com/Paitesanshi/CharacterBox)以 MIT 许可公开 10 部剧本的预处理 scenes 及 simulator。场景文件中确实含地点、人物、描述与 action 字段，适合研究动作文本怎样携带对象、场景和结果。

但论文的核心是 narrator agent 与 character agent 在文本世界中运行，仓库 README 也把这些数据描述为运行/评估的预处理 scene。它没有把 action 字段说明为独立采集、可用作 held-out 人类行为的轨迹，也没有逐角色的私有知识记录。故不能把它的 simulator 输出拿来证明本项目内部状态有效；最多可用于之后的 scene/action ontology 试验。

### SOTOPIA：可用的外部合成代理，不是现实行为金标准

[SOTOPIA 官方仓库](https://github.com/sotopia-lab/sotopia)当前提供 `sotopia` 与 `sotopia-pi` 数据安装入口，二者许可证均为 CC-BY-SA 4.0。其安装清单明确给出数据 dump；代码采用 `EpisodeLog` 保存和导出既有 episodes。原始 [SOTOPIA 论文](https://arxiv.org/abs/2310.11667)定义有 private social goals；项目已有核读确认“其他角色目标不可见”。这让它成为目前唯一同时满足“可取得”“连续 action log”“至少一层信息不对称”的候选。

限制同样决定性：SOTOPIA 的公开 benchmark 是交互环境和 episode-level social evaluation；SOTOPIA-π 的 behavior-cloning 轨迹明确由 GPT-4 expert policy 等 agent 交互产生。它不是现实人物连续行为，也不是小房间微行为。若采用，允许的表述是：**在外部、可复现的合成社会轨迹上测试表示/信息干预协议**；不允许表述为“预测真实人类行为”或“心理学验证”。

## 决策：数据路线拆成两条，不能混写

### 路线 A：当前 demo 的机制审计 fixture

用小房间、有限动作和预先写定的 W/O 对照，建立 20–40 个**人工编写的对比 trace**。用途是检查：同一 W 不同 O、同一终局不同历史时，`ΔO → ΔX → ΔS → Δπ` 是否按预期发生；并作为代码回归测试。

它不提供独立统计性 `A*`，因此不报告“预测优于 baseline”。

### 路线 B：SOTOPIA 外部合成 Replay 小切片

下一步只做可行性 pilot，而非大规模实验：取得一个公开 dump，导出 **30 个 episode 的开发切片**，逐条检查以下字段是否能保留：

- actor、turn order、过去 action、当前 action；
- scene、每名角色 profile / private goal；
- 哪些信息能进入该 actor 的 `O`；
- provenance（human / expert agent / self-play / unknown）；
- train/dev/test 的 episode 级切分，禁止同一 episode 的相邻 turn 跨集合。

只有当这 30 条能被映射为一个冻结的动作 ontology、且不泄漏未来文本时，才建立 persona/raw-history/summary/state baseline。若做不到，应记录为“外部数据不适配当前协议”，而不是改写 `W/O` 定义去迎合数据。

## T0b 实测结果（2026-09-05）

已从官方 `cmu-lti/sotopia-pi` RDB 导出 30 条确定性开发切片，原始 RDB SHA-256 为 `324C037F4AC3CA6605C800BFE74EB1C11B05ED8C96C26DF48C7560A7DAC90DA2`。完整 dump 有 32,663 个 `EpisodeLog`；本切片包含 25 个 agent profile、26 个 environment profile。原始官方 SOTOPIA dump 链接当日为 404，因此本次是 SOTOPIA-π 的公开 dump，不得偷换成原始 SOTOPIA 语料。

**通过的条件**：30/30 条都有两名 actor、顺序 messages 和非 idle action；30/30 条初始 prompt 都对自身给出具体 goal、对另一角色写出 `Unknown`。因此，`W/O` 的信息边界能在该格式中被忠实保留。

**未通过的条件**：

1. `EpisodeLog` 没有 episode-level 的 human / expert-policy / self-play provenance 字段，所有导出记录必须标为 `unknown_within_dump`；
2. 491 个 actor action surface 记录中，279 为 `did nothing`、187 为 `said`、17 为 `left the conversation`，其余仅 8 条为不统一的自由文本 action / non-verbal communication；
3. 这意味着 raw text 不能直接映射为当前有限 `A^O`，而粗暴压成 `{say, idle, leave}` 又会删除本项目要比较的行为差异。

**判定**：T0b 对“外部合成 trajectory 的信息边界与 trace 格式”通过；对“可立即进入有限动作 Replay / T14–T17 的独立 `A*`”不通过。切片和 manifest 留在 Git 忽略的 `outputs/sotopia_t0b_2026-09-05/slice/`，导出器版本化于 [`02_实验/T0b_sotopia`](../02_实验/T0b_sotopia/README.md)。

## 已冻结的停止条件

- 不以 simulator 自生成轨迹声称 S 有预测效力；
- 不把 SOTOPIA 的 agent 轨迹称为真人 ground truth；
- 不因 BehaviorChain 论文有 benchmark 名称就假设数据可下载；
- 在路线 B 可行性通过前，不启动 T14–T17 的正式模型比较；
- 在真实数据路线未定前，不继续扩展 Q01、ToM、P 字段或动作集来“准备实验”。
