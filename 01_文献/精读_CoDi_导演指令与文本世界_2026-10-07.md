## 结论先行

**[论文证据]** CoDi 把全局叙事 utility 与角色 utility 分开，让 Director 使用角色指令、世界干预、结果描述和终止四类权限。它是直接近邻，不是单次写故事；但世界和角色动作主要是累积文本，没有展示独立 W validator/settlement。论文只有 LLM 评测，不是人类玩家实验。

## 1. Setup 与角色目标

**[论文证据｜pp.72–73]** Planner 从 prompt 生成 characters/places/items、自然语言初始状态和全局/角色 utility，最多自我修订 3 轮。静态画像与动态 goals/desires 分开；角色按画像重新初始化自身 utility，不读全局 narrative goals。utility 在这里主要是提示中的目标/加分规则，不是训练所得数值 policy 或一个完整动作优化器。

使用 GPT-4o-2024-11-20 作为 Planner，Gemini-2.0-Flash 作为 Director/Character/Editor；未报告微调或 RAG。Editor 把模拟文本改成剧本/小说，呈现层与过程要分开。

## 2. Director 的四种计算分支

**[论文证据｜pp.73–74，Figures 4–5]** 读取 setup 摘要、utility 和累计 story progress，输出 Reason/Choice/Instruction：

| Choice | 写入或协调的内容 | 不可误称 |
|---|---|---|
| Character | 选择人物、地点和高层 performance instruction，再由该角色响应 | 角色完全不受导演指令影响 |
| Description | 描述行动/事件后果，补足读者看不见的变化 | W 已机器校验并真实结算 |
| Intervention | 新事件、环境变化、未在 setup 定义的角色 | 受固定资源/实体预算约束的世界操作 |
| Ending | 列出目标及故事中支持其完成的证据，终止 | 结构化状态保证全部硬约束成立 |

角色优先自身画像/utility，收到导演指令可作符合 persona 的解释。响应含 private Thought 及 Action/Emotion 或 Speech；其他人物 Thought 从上下文滤去。**仅滤想法不等于场景、消息、地点的完整局部观察权限。**

**[Luna 源码核查]** [generation.py](https://github.com/Speeditidious/CoDi/blob/dbbed527dc26f3aa830ea608a1565b2a67511ad5/generation.py) 与 [director_agent_utils.py](https://github.com/Speeditidious/CoDi/blob/dbbed527dc26f3aa830ea608a1565b2a67511ad5/director_agent_utils.py)把干预追加进 story progress；每 100 turns 重构角色 utility。非法角色名有有限重试，超限可转临时 NPC/intervention；最大 turn 后尝试收尾，仍未正常完成可截断。没有通用不可达证明或世界事务回滚。父代理未运行这些分支。

## 3. 实验：不是玩家得分

**[论文证据｜pp.75–78]** 使用 55 个 TELL ME A STORY 测试 prompts；与 HoLLMwood 共用 setup/backbone，另比较 human-written stories。Gemini-1.5-Pro 裁判，AB/BA 反向排序；反转偏好/同等记平局。不能将与人写故事对比误称为“人类评审”。

Table 1 的“81.8%”是 LLM 对目标按 0/0.5/1 打分后的平均（部分完成算 0.5），不是 81.8% 轨迹满足所有硬目标。删除 Intervention 降至 62.5%，删除 Description 为 81.7%；证明这套生成/评分条件下干预有作用，未隔离可执行世界干预、候选注入、玩家因果理解或作者劳动。

Table 3：默认版 55 条中 1 条到 200-turn 上限；结构化版总均数 206 turns，是多个阶段累计，阶段分别出现 0/1/0/2 条强制退出。不能说结构化版“没有失败”。文章明确承认人类评估是否复现、角色能否真正违背导演及更复杂交互仍未知。

## 4. 对本项目的意义

可借：目标集合与角色目标分离；记录不同干预权限；用真实消融而不是总体非空断言；结果呈现不应替执行器制造事实。需要防：Director 一面创造情境、一面写 outcome、再评节点达成，把自证混进成功率。

CoDi 说自己受 Sabre 启发，不等于 Sabre 也只用隐式文本状态；Sabre 的符号执行/角色信念机制见[前轮审计](调研子审计_AuthorGoals与叙事规划_2026-10-07.md)。IBSEN 是进一步玩家参与的线索，本轮未精读，不加成已覆盖的 benchmark。
