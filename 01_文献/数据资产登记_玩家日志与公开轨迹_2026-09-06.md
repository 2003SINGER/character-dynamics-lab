## 选择边界

第一批不追求“一个万能数据集”。优先顺序是：文本玩家轨迹（ClubFloyd）验证 adapter 结构；PowerWash/AGAIN 验证外部状态 proxy 与时间动态；LIGHT 接入 character/world；HEART-BENCH 与 PersonaX 只作 memory/trait 对照。所有 LLM 转换字段必须保留模型、prompt 版本、confidence 和 `unknown` 选项。

本轮实际检查了 [JerichoWorld 仓库](https://github.com/JerichoWorld/JerichoWorld)：其公开包结构适合验证 `state → action → next_state` 的接口，但 README 明确是 walkthrough/data-collection agent 轨迹，因此不能替代 ClubFloyd 的真人玩家证据。ClubFloyd 的公开统计已由论文核验，原始 transcript 的长期保存与许可仍待单独确认。
