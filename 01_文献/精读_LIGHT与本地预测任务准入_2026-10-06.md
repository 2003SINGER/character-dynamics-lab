## 结论先行

**项目决定：当前 LIGHT 视图仅准许 DEVELOPMENT 条件预测；Paper-0 formal admission 仍 NO-GO。** PredictionBaselineV1 的训练和复现没有作废，但其问题是“环境快照 + 同角色既往物理动作 → 来源下一物理动作”，不是完整观察历史预测，也不是人物心理模型。不要通过加状态或调 GRU 补救被视图丢掉的信息。

这次确认的具体弯路是：我们认真测试了模型和 split，却一直把局部 `context` 字段叫 O、把物理动作子序列叫 history，没有先检验它们与拟研究的信息范围是否一致。字段名与复制正确性不是研究任务的准入证明。

## 论文实际主张

**论文证据：**§3 收集人类之间的幻想角色交互，每轮允许说话及物理动作/表情；人物获得 persona 和环境信息。§4 的预测输入有 dialogue、persona、环境与 self/partner 动作等通道；physical action ranking 通常使用可执行候选。§5.4 比较不同通道，明确指出对话对动作预测的重要性。这里研究的是受控游戏中的角色扮演行为，不是日常生活心理状态的测量。

**历史交互实现证据：**论文 Appendix D / Figure 9 展示自己的 persona、setting、动作下拉框、自由文本与对话/动作结果 feed。官方 ParlAI `2019-03-21@d4e3b1c76360bcf72cbae541834f8cd38f5449ee` 的 [worlds.py](https://github.com/facebookresearch/ParlAI/blob/d4e3b1c76360bcf72cbae541834f8cd38f5449ee/parlai/mturk/tasks/light/light_chats/worlds.py)（Git blob `5c3e813e8d25a8d1016314f9120a53176082861d`）与 [custom.jsx](https://github.com/facebookresearch/ParlAI/blob/d4e3b1c76360bcf72cbae541834f8cd38f5449ee/parlai/mturk/tasks/light/light_chats/frontend/components/custom.jsx)（blob `bd3ba21881a15e464ba0219f49cd67fd2797ea14`）也明确实现：先给 worker persona/context/actions；speech 与选择的 action 一起提交；执行物理动作后刷新双方环境，并把结果传给对方。主代理独立读回相关路径。**对方收到的物理动作是 `graph.get_text(other_agent_name)` 的结果描述，不是直接广播命令字符串**；gesture 才直接传字符串。

**尚未证实：**在该固定历史 tree 中未找到 collection log → `light-dialog-processed-small7.pkl` 的确切转换器。因此 unknown 是收集日志与处理后逐轮数组的映射、时点和版本关系，不是“2019 worker UI 完全未知”。不能认定 `context[i]` / `available_actions[i]` 在 small7 中是 action 前记录，不能把同轮 speech 当作预测当前动作的已知输入，也不能把 raw partner action 命令当作原样可见消息。没有用现代 quests 或当前 [ParlAI builder](https://github.com/facebookresearch/ParlAI/blob/main/parlai/tasks/light_dialog/builder.py) 填补这个缺口；后者仅是下游 teacher 参考。

| 层 | 实际保留/变换 | 已核验的边界 |
|---|---|---|

**实现证据：**主代理独立重做全量 join：先用非空 physical actions 建立 physical-step → raw-turn 映射，再比对原始数组，而不是直接用 `target_step_index` 索引 raw turn。

- 13,463 / 13,463 行的 O、动作、候选列表及 normalized actor 精确对应来源；13152 行的 physical index 与 raw turn 不同。不存在本轮发现的错位复制或标签由本模型生成问题。
- 同轮 `speech` 在 13,456 行非空，但未进入此训练视图。**这只能证明遗漏了一个 co-recorded 通道，不能证明 speech 当时可作动作预测输入。**修复时不能把同轮 speech 无条件补回去。
- 当前全部 13,463 个 O 都以 `You are in ` 开头；physical history depth 分布为 1:6869、2:3723、3:1804、4:783、5:236、6:48。它是短 physical history，不是数小时/多日生活序列。
- 这些事实不说明 history 无用、标签错误或 S 必然有用；它们限定了上一轮结果的 estimand。

## 支持集、重复与快捷方式检查

**实现证据：**[结构审计脚本](../tools/audit_light_prediction_admission_v1.py)不训练模型；最终产物为 `outputs/light_prediction_admission_20261006/run_v3/`。v1/v2 是较早脚本版本，保留但不引用为最终结果。split 仍按完整 episode SHA 分桶；bucket 9 只做结构计数，不用于快捷方式评分。

| 结构检查 | Train | Development validation |
|---|---:|---:|
| 原始行 | 9530 | 2717 |
| 唯一 normalized gold 支持 | 9488 | 2707 |
| normalized gold 歧义 | 42 | 10 |
| gold 缺席 / 空或坏候选 | 0 / 0 | 0 / 0 |
| exact prior O/action pair 重复 | 446 | 130 |
| 相同精确 O 却有多个 gold 的组 | 875 / 8307 | 261 / 2356 |

相同 O 的多个动作可能来自历史、人格、对话或正常随机选择；**不能仅据此判 O 非法、证明状态必要性或要求确定性标签。**歧义候选仍排除，不补 gold、不合并词条、不改旧训练结果。

train 众数 gold position 为 0；在 2707 个 unique-support validation targets 上，固定选 first 为 310/2707（11.45%），last 为 326/2707（12.04%）。这是有限位置快捷方式诊断，不是与旧 NLL 的等指标模型比赛，也不是“所有泄漏已排除”。训练器的共享 candidate scorer 本来不接收候选位置。

当前 O 逐字包含 target 的行 train/validation 各 1：均出现在环境叙述（村民穿植物衣服、国王要求穿金衣服），不是明确的当前 action 标签字段。文字匹配只是筛查 proxy；这 2 行既不自动判泄漏，也不自动判无泄漏。旧结果不据此重算或筛选。

## 准入矩阵与项目决定

| 必要条件 | 本轮结论 | 后果 |
|---|---|---|
| 来源动作不由本项目 dynamics 生成 | 来源/逐字段映射已复核 | 可作受限来源标签 development supervision |
| 输入包含完整合法观察历史 | 旧训练视图不完整；新候选的源时序/可见表示未准入 | 不检验完整 history 的充分性，不归因心理机制 |
| 本地 support 等于角色 `A^O` / 确切来源显示菜单 | 历史界面有菜单证据；small7 对应关系未证明 | 保留 recorded support 命名，Paper-0 NO-GO |
| 未暴露独立 test / user grouping | 未具备；source worker ID 不在此视图 | 不将 bucket 9 或旧 test 改名正式 test |
| 人工 semantic admission | PENDING | 自动脚本 PASS 不等于人类准入 |

## Before-turn 重建：已验收的信息流与未验收的来源时序

**实现证据：**新产物 `outputs/light_before_turn_20261006/run_v1/` 保留原 13,463-target cohort 与冻结 episode split，不改旧模型、旧输入或拟合结果。每个候选 payload 包含唯一匹配的 self persona、当前 recorded environment snapshot、严格过去的两角色 speech/action/emote；history 按 raw turn 分组，不虚构同轮 channel 的先后。`recorded_support` 独立存为 candidate surface；来源 label 独立存为 supervision；source ID、索引、speaker 原名和 split 只属于 provenance。partner persona、全局 descriptions、同轮输出和未来 turn 不进入候选 payload。不存在合格 speaker、persona 唯一匹配或数组对齐时拒绝，而非静默丢掉历史。

主代理在完整 cohort 独立逐项重建了 payload、raw-turn refs、来源 label 和 split；总计 116,961 个 prior-turn groups，过去 speech 为 self 54,865 / partner 62,064 个、action 为 24,327 / 18,908 个、emote 为 9,441 / 10,299 个。这些是**跨目标重复出现的历史项计数**，不是 unique event 数或效果量。全部 target 都有 prior partner speech，9,397 个有 prior partner action；只是通道存在，不证明预测增益。

| 验收 | 证据 / 范围 |
|---|---|
