日期：2026-10-06。阅读等级：Codex/Luna 核对官方论文正文、主代理独立复核 adapter 与全量来源映射；不是用户精读记录。论文单独附录未审，不声称已恢复 2019 worker UI。

原文：[Urbanek et al., EMNLP-IJCNLP 2019](https://aclanthology.org/D19-1062/)；[本地官方 PDF](PDF/2019_LIGHT_Learning_to_Speak_and_Act.pdf)，11 页、203,633 bytes，SHA-256 `18226b3a54122cd0c5e9629cf0addf4cb015ab7d28b64c51ba131d0e5547b350`。已核验标题、页数与第 3 页的任务/收集流程；原文件不改。

## 结论先行

**项目决定：当前 LIGHT 视图仅准许 DEVELOPMENT 条件预测；Paper-0 formal admission 仍 NO-GO。** PredictionBaselineV1 的训练和复现没有作废，但其问题是“环境快照 + 同角色既往物理动作 → 来源下一物理动作”，不是完整观察历史预测，也不是人物心理模型。不要通过加状态或调 GRU 补救被视图丢掉的信息。

这次确认的具体弯路是：我们认真测试了模型和 split，却一直把局部 `context` 字段叫 O、把物理动作子序列叫 history，没有先检验它们与拟研究的信息范围是否一致。字段名与复制正确性不是研究任务的准入证明。

## 论文实际主张

**论文证据：**§3 收集人类之间的幻想角色交互，每轮允许说话及物理动作/表情；人物获得 persona 和环境信息。§4 的预测输入有 dialogue、persona、环境与 self/partner 动作等通道；physical action ranking 通常使用可执行候选。§5.4 比较不同通道，明确指出对话对动作预测的重要性。这里研究的是受控游戏中的角色扮演行为，不是日常生活心理状态的测量。

**未证实：**2019 具体 worker 是否从菜单选择、`small7` 中候选何时生成/展示、同轮 speech 与 action 的输入先后。本次没有用现代 LIGHT UI、后来的 quests 处理器或当前 ParlAI teacher 代替原 collector。官方 [ParlAI builder](https://github.com/facebookresearch/ParlAI/blob/main/parlai/tasks/light_dialog/builder.py) 是下游 teacher 输入构造参考，不是本项目直接映射的 exact source producer。

## 本地数据流：逐字段实证

| 层 | 实际保留/变换 | 已核验的边界 |
|---|---|---|
| 官方 processed `light_data.pkl` | `context / action / available_actions / speech / emote / agents` | 文件 SHA 与下载入口声明一致；10,268 episodes，不据此推断 worker identity 或用户独立 split |
| [export_replay.py](../02_实验/T0c_LIGHT/export_replay.py) | 非空 action 的同 raw-turn context、action、候选原样复制；speech/emote 独立存入 source context | 字段复制，不是完整 actor-visible observation 重建 |
| [actor-local gate](../02_实验/T0c_LIGHT/run_actor_local_history_gate_v0.py) | 同 episode/actor 的 prior physical O/A；首个 physical 动作只做 prior | `target_step_index` 和 `previous_same_actor_t` 实为过滤后的 physical-step index，不是 raw turn 或分钟 |
| [PredictionBaselineV1](../02_实验/PredictionBaselineV1/README.md) | 当前快照、prior same-actor physical O/A、记录候选 | 不输入 dialogue、emote、partner action history 或 persona；不构成完整 `H^obs` |

**实现证据：**主代理独立重做全量 join：先用非空 physical actions 建立 physical-step → raw-turn 映射，再比对原始数组，而不是直接用 `target_step_index` 索引 raw turn。

- 13,463 / 13,463 行的 O、动作、候选列表及 normalized actor 精确对应来源；13152 行的 physical index 与 raw turn 不同。不存在本轮发现的错位复制或标签由本模型生成问题。
- 同轮 `speech` 在 13,456 行非空，但未进入此训练视图。**这只能证明遗漏了一个 co-recorded 通道，不能证明 speech 当时可作动作预测输入。**修复时不能把同轮 speech 无条件补回去。
- 当前全部 13,463 个 O 都以 `You are in ` 开头；physical history depth 分布为 1:6869、2:3723、3:1804、4:783、5:236、6:48。它是短 physical history，不是数小时/多日生活序列。
- 这些事实不说明 history 无用、标签错误或 S 必然有用；它们限定了上一轮结果的 estimand。

## 支持集、重复与快捷方式检查

**实现证据：**[结构审计脚本](../tools/audit_light_prediction_admission_v1.py)不训练模型；最终产物为 `outputs/light_prediction_admission_20261006/run_v3/`。v1/v2 是较早脚本版本，保留但不引用为最终结果。split 仍按完整 episode SHA 分桶；bucket 9 只做结构计数，不用于快捷方式评分。

| 结构检查 | Train | Development validation |
|---|---:|---:|
| 原始行 | 9530 | 2717 |
| 唯一 normalized gold 支持 | 9488 | 2707 |
| normalized gold 歧义 | 42 | 10 |
| gold 缺席 / 空或坏候选 | 0 / 0 | 0 / 0 |
| exact prior O/action pair 重复 | 446 | 130 |
| 相同精确 O 却有多个 gold 的组 | 875 / 8307 | 261 / 2356 |

相同 O 的多个动作可能来自历史、人格、对话或正常随机选择；**不能仅据此判 O 非法、证明状态必要性或要求确定性标签。**歧义候选仍排除，不补 gold、不合并词条、不改旧训练结果。

train 众数 gold position 为 0；在 2707 个 unique-support validation targets 上，固定选 first 为 310/2707（11.45%），last 为 326/2707（12.04%）。这是有限位置快捷方式诊断，不是与旧 NLL 的等指标模型比赛，也不是“所有泄漏已排除”。训练器的共享 candidate scorer 本来不接收候选位置。

当前 O 逐字包含 target 的行 train/validation 各 1：均出现在环境叙述（村民穿植物衣服、国王要求穿金衣服），不是明确的当前 action 标签字段。文字匹配只是筛查 proxy；这 2 行既不自动判泄漏，也不自动判无泄漏。旧结果不据此重算或筛选。

## 准入矩阵与项目决定

| 必要条件 | 本轮结论 | 后果 |
|---|---|---|
| 来源动作不由本项目 dynamics 生成 | 来源/逐字段映射已复核 | 可作受限来源标签 development supervision |
| 当前视图包含完整合法观察历史 | 不满足完整性；时序权限未审完 | 不检验完整 history 的充分性，不归因心理机制 |
| 候选等于角色 `A^O` / 历史显示菜单 | 未证明 | 保留 recorded support 命名，Paper-0 NO-GO |
| 未暴露独立 test / user grouping | 未具备；source worker ID 不在此视图 | 不将 bucket 9 或旧 test 改名正式 test |
| 人工 semantic admission | PENDING | 自动脚本 PASS 不等于人类准入 |

24 条 train/validation 样本已按固定结构 strata/SHA 顺序生成在 `run_v3/review_24.jsonl`；所有人工字段保留 `PENDING`。它只是此 flattened view 的核对包，没有完整 raw-turn/future 语义上下文；不是总体抽样估计，也不是独立 reviewer 的通过证据。原始数据及全部拟合 artifacts 未改。

**唯一下一动作：**做 source-preserving 的 before-turn 输入重建 feasibility：保留 raw-turn provenance，区分严格过去的 dialogue/可见动作、self persona、环境快照和同轮待定输出；用时序负控确认不读当前 action 或未来 turn。先验收信息契约，再冻结新的预测 protocol；不立即重训、不调 Demo/Runtime、不把新视图冒称已验证 `A^O`。
