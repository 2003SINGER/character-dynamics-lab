## 结论先行

**项目仍值得做，但不能以“动态 persona”“心理状态更新”“连续行为预测”“角色遮罩”任一单点为贡献。**

最直接的相近工作已分别覆盖：连续人物行为预测（BehaviorChain）、文本世界行为轨迹（CharacterBox）、时间化角色 belief（TimeToM）、多时间尺度心理状态和漂移修复（Dynamic Persona Coherence）、情境激活人格（Trait Activation）、以及长程叙事承诺（NCP-Bench）。

项目仍可核验的空间不是“有没有 state”，而是：

> 在一个受控、可回放且部分可观测的角色环境中，能否把**历史、角色可知信息、状态表示和行为不确定性**分开干预，并检验模型的行为分布是否同时满足预测力、历史敏感性、信息边界与适当的稳定/变化？

这是 `project decision`，不是论文已经证明的 gap。它要求先以文献复核后的最小 trace 来验证，尤其要防止把模型的叙事先验、角色身份泄漏或 LLM judge 偏好误当人物动力学。

| 项目核心 | 已有 paper evidence | 本项目仍须验证 |
|---|---|---|
| 连续下一行为预测 | BehaviorChain 已有 persona、历史、场景下的连续行为预测，并报告自回归错误雪球 | 是否能在**同一终局、不同历史**和**同一事实、不同可知信息**的干预下测到正确的分布变化 |

| 长程一致性/漂移 | DPC、ANCHOR、NCP-Bench 都测不同形式的长期失败 | “过冲、恢复缺失、状态跳变”需定义为可量化现象，不可只写案例 |
| 评估有效性 | Story Shapes the Agent 证明叙事 framing 可压过 persona；Identity Leakage 说明角色身份会污染评测 | 必须使用结构同构/匿名化/固定动作集等控制，不能只让 LLM judge 给“像不像”分 |
| 心理学机制 | appraisal 与情感动态已有多种计算实现 | 心理学理论是候选 update operator；不能视为人物真实性的 ground truth |

## 研究边界的修订

### 已被实质占用的表述

- “提出动态 persona / 多时间尺度心理状态”；
- “根据历史连续预测角色下一行为”；
- “在文本世界里让角色按心理机制行动”；
- “为角色维护时间化 belief / 信息不对称”；
- “检测/修复长期 persona drift”。

这些均为 `paper evidence` 支持的相邻覆盖；具体论文之间是否完全同任务，仍需以精读笔记中的实验输入输出确认。

### 尚未确认被完整覆盖、但绝非自动 gap 的组合

1. **同一客观最终场景、系统性改变角色历史**：评价 `P(action)` 是否以预先规定的方向/幅度变化；
2. **同一客观世界、系统性改变角色可知信息**：测未知事实不泄漏、错误 belief 能驱动行为、纠正信息能更新行为；
3. **状态的预测充分性**：在相同信息预算下比较 raw history、summary、structured state 对下一行为与干预响应的保留程度；
4. **条件不确定性**：不是固定 temperature，而是对习惯/冲突/信息不足等情境下行为分布熵和校准的测量；
5. **结构同构控制**：换叙事皮肤不换动作/转移规则，分辨 narrative prior、persona 与历史状态各自的作用。

上述五点是 `open question`。它们必须在下一轮查全 ToM、counterfactual role-play、causal evaluation 和 affective-agent 文献后才可被写作“gap”。

## 可立即参考的方法与方式

| 目标 | 可借方法 | 使用条件 |
|---|---|---|
| 可回放状态 | BehaviorChain 的 teacher-forcing 链与 PSR 的未来预测观 | 回放时强制写入 canonical event，不能让预测误差污染下一步 |
| 信息边界 | TimeToM 的角色已知时间线 | `world fact`、`observation`、`belief` 必须是不同字段，禁止以 prompt 文字混写 |
| 反混淆评测 | Story Shapes 的结构同构任务 | 固定 action space、转移和目标，只替换叙事皮肤 |
| 长程诊断 | ANCHOR 的身份/轨迹分拆；DPC 的 identity/adaptation 区分 | 不可把“记住资料”当作“行为动力学正确” |
| 动态状态 | PSR、层次 state-space、appraisal temporal network | 将其当对照机制/记录格式，先验证而非预设人类心理真值 |
| 世界约束 | CharacterBox 与 NCP-Bench 的结构化环境/承诺 | 世界只能结算合法 action；主观解释不能直接写回 world fact |
| 抗泄漏 | Identity Leakage 的匿名化思想 | 小说名、人名、标志性专名与后续剧情线索需要屏蔽或改写 |

## 项目决定与停止条件

- `project decision`：第一阶段优先做**评测/诊断 trace**，而非先实现心理学状态引擎或游戏世界。
- `project decision`：最小比较至少含 raw history、summary/history state，以及一个显式 state；有无信息遮罩应能单独消融。
- `project decision`：若 raw history 或 summary 在预先冻结的 history/information interventions 上已经稳定通过，项目不应把显式 state 发展为方法主张。
- `open question`：是否能为“正确变化方向/幅度/熵”建立非循环的标注或 judge 协议；这将决定本项目是严谨评测还是漂亮案例集。

### 第一优先（决定是否还有题）

1. [Generative Agents](PDF/2023_Generative_Agents_Interactive_Simulacra_of_Human_Behavior.pdf)：优先核验独立 sandbox、对象状态与局部观察如何接入角色；不要把其 memory/retrieval 误说成 predictive state。
