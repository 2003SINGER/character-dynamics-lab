## 2. 当前实际执行链

[advance_one_decision](../Demo%20codex-generated/Src/simulation.cpp) 被终端与 batch 共用：

先用上次结算刷新 O → appraise → update_state（含上次实际 Δt）→ decide → sample → W 内部展开/结算 → **把可感知的 self-action feedback 写入 O，再由 O 更新 commitment** → 如有睡眠感知则局部写 O → 保存本次 outcome。

注意：身体/心理数值对本次动作的后果主要在下一决策点更新，commitment 在结算后立即更新。因此 CSV 的 pre/outcome/post 不是同一时刻的全量同步快照；也不能说所有 S 后果都已进入本行 post。

### 5.3 为什么同时报告两种 NLL（历史候选定义）

这批数据用**生成它的同一规则 π(A)**回算 chosen action 的 NLL，只是检查记录和归一化口径，不是模型比较；并且它来自旧版 `W.available_actions() → A^O`。当前分支已改为 visible-object affordance，因此以下 65,536 行的 `|A^O|` 与 NLL 分布**仅是历史 smoke evidence，不能描述当前模型**：

| `|A^O|` | 行数 | 原始 NLL 均值 | `NLL / ln|A^O|` 均值 |
|---:|---:|---:|---:|
| 9 | 20,553 | 1.490 | 0.678 |
| 10 | 28,748 | 1.600 | 0.695 |
| 11 | 5,713 | 1.849 | 0.771 |
| 13 | 6,696 | 2.192 | 0.855 |
| 14 | 3,826 | 2.315 | 0.877 |
| **总体（描述性）** | 65,536 | **1.689** | **0.723** |

原始 NLL 随候选数增加而上升，其中一部分只是"题更难"；归一化列说明它相对均匀随机基线的比例。**以后论文/报告必须同时给出表内两种数，不可用总体 1.689 或总体 0.723 单独支持任何主张。**

### 5.4 已知边界

- 当前 `known_action_count` 是 `A^O`（角色知道的动作数），而 `DecisionContext` 还会用阈值压低某些候选的概率。现有定义下分母用 `ln|A^O|` 是一种**预注册口径候选**，要在第一次真实模型比较前冻结；不能在看过各模型结果后选择更有利的分母。
- 本 batch 的 π(A) 来自同一套规则，故“自评分”必然相对随机好；**这不证明 S、Q01、Focused/Halfhearted 或任何心理学机制有预测价值。**

### 5.5 推送后的两个规则诊断（描述性、不属于当前候选语义，也不是研究结果）

1. **候选集量尺诊断**：重新计算的分层 NLL 与 §5.3 相同；`|A^O|` 从 9 增至 14 时，原始 NLL 从 1.490 增至 2.315，而归一化均值从 0.678 增至 0.877。它只说明 T25 已能暴露不同候选规模的难度差异，不能将总体值当作模型效果。
2. **拆分动作可达性诊断**：`StudyFocused` / `StudyHalfhearted` 分别有正概率于 10,452 / 10,508 行，实际被采样 1,587 / 1,188 次；在两者都为正概率的 10,443 行中，按 boredom 的 Q1/Q3 分组，Focused 概率为 0.1644 / 0.1338，Halfhearted 为 0.1049 / 0.1206；按 satisfaction 的 Q1/Q3 分组，Focused 为 0.1416 / 0.1517。方向与现有手写系数相符，但样本未控制 task pressure、fatigue、时间与选择性进入，且来源就是同一 policy，**不能**解释成 Q01、P 或任何心理机制得到验证。

这轮诊断发现：概率列中的 0 同时可能表示“该动作不在 A^O”与“动作在 A^O 但被阈值抑制”。T25c 已用每个实际动作的 `known_<action>` mask 解决：本轮 65,536 行中，零概率格里有 282,744 个 `known_but_suppressed`、372,664 个 `not_known`。这两类不应在真实 Replay 中混作同一种失败；旧 T25 batch 仍不可据概率列单独复原具体支持集。
