# Theory-S M1 freeze decision｜2026-09-07

本页是 M1 的 pre-training protocol freeze，不提出新机制。冻结后，机制代码不再扩展；后续工作转入 M2/M3/T0d/D01 的数据、候选集、O/A* 与语义准入。

## 1. State identity anchors

当前状态字段仍为 `fatigue`、`engagement`、`tension`。

| relation | status | rationale / boundary |
|---|---|---|
| `effort_load → fatigue` positive | project identity anchor; literature-motivated | effort/resource interpretation defines the candidate field; not a fixed effect size |
| `recovery_cue → fatigue` negative | project identity anchor; literature-motivated | recovery is a candidate return-to-baseline cue; not a medical claim |
| `negative_conduciveness → tension` positive | project identity anchor; literature-motivated | obstruction/threat-like appraisal candidate; exact mapping remains data-dependent |
| `recovery_cue → tension` negative | project identity anchor; engineering recovery prior | retained for the current candidate definition, not claimed as universal psychology |
| `goal_relevance / positive_conduciveness / social_opportunity → engagement` positive | project-definition anchor with literature-motivated candidates | engagement means broad behavioral involvement, not positive valence; these inputs express the project definition and remain empirically revisable |
| all other `β` edges | free | no hard zero and no implied literature topology |

The implementation expresses these as a soft sign prior only. It does not
claim that the literature supplies a sparse matrix, and it does not force a
minimum effect size in the scientific interpretation.

## 2. Anchor regularization protocol

- The formal semantic prior is **sign-violation regularization**: penalize only
  `sign_prior * β < 0`.
- `margin=0.05` and `anchor_weight=0.05` in the current synthetic smoke are
  regression fixtures only. Neither is a theory constant or a formal-test
  hyperparameter.
- Before any real development training, select anchor weight on a development
  split using a pre-registered rule and report the unregularized NLL plus the
  anchor penalty. Do not tune it on held-out formal test data.
- A future protocol may use zero-margin sign penalty or an explicitly chosen
  small margin, but that choice belongs to the development protocol, not M1's
  semantic definition.

## 3. Time scale

- The current operator indexes one replay **decision step** per update.
- `alpha` therefore means persistence per decision step in this compatibility
  slice; it is not a physical-time half-life.
- A dataset with irregular elapsed time must either provide a frozen adapter
  that maps `Δt` to a pre-specified update convention or be restricted to a
  regular-step subset. Do not mix raw decision-step alpha across datasets with
  incompatible clocks.

## 4. Initial state and boundaries

- Each trajectory starts at its own neutral equilibrium `S_0 = sigmoid(b)`;
  there is no hidden burn-in and no state carried across trajectory boundaries.
- `S_0` is part of the model's declared initialization, not an inferred prefix
  from future rows. A later protocol may compare fixed-neutral and burn-in
  variants only as a pre-registered development ablation.
- At each step, construct `X_t` from information available through `O_t` and
  the past transition; form `S_t` and logits; reveal `A*_t` only for the loss.

## 5. Freeze status

M1 is complete as a trainable-dynamics protocol gate. This does not claim that
the fields are psychologically true, that the anchors are causal facts, or
that predictive validity has been shown. No further v2.x mechanism, topology,
state field, appraisal schema, or P-network is authorized by this decision.
