# 审核：整合系统视角下的判断复核

> 日期：2026-09-05
> 触发：用户——「我们弄得是一个**整合系统**，所以曾经在**有其他部分短板**的情况下做的判断可能不成立。所以你要再帮我看看审核。」
> 方法：不是重读文献，而是**回到实现本身**，核对每条判断所依赖的隐含前提在系统里是否真的成立。
> 结论摘要：**查出 1 条判断前提不成立、1 条待决问题在当前实现下不可检验、1 条阈值设定方式有必然失败风险。** 另加 3 条整合系统特有的新风险。

## §0. 一句话结论

我此前论证「Gap 1a 在本项目不成立」时，用的是「**项目是文本/结构化动作，词汇近乎无限**」这个前提。

**回到代码看，这个前提是错的。当前动作集是 16 项封闭枚举，没有强度参数。**

这不推翻整条论证，但把结论从「不成立」改成「**部分成立，且成立的部分精确地限制了可测效应量的上限**」。更重要的是，它连带使得 **Q01 在当前实现下不可检验**。

## §1. 【最严重】Gap 1a 的「不成立」判定，前提不成立

### 1.1 我此前写了什么

`前台问题与候选创新.md:185`：

> | **Gap 1a** | "模拟的状态不会渗透进行为" | **是** | **在本项目里不成立**——项目是**文本/结构化动作，词汇近乎无限**（Gap 3 已打破）。Rabin 自己举的例子（2 个音效 + 4 个动画）在本项目不适用 |

### 1.2 实际实现是什么

`Demo codex-generated/Inc/action.h:6`：

```cpp
enum class ActionType {
    UsePhone, ShopOnPhone, UseComputer, StudyAtComputer, StudyAtDesk,
    RestAtBed, SleepAtBed, GoToBathroom, GetMeal, TurnLightOn, TurnLightOff,
    TurnOffAlarm, OpenCurtain, CloseCurtain, Idle, Count
};
```

**16 个动作类型。** 且：

```cpp
struct ActionDefinition {
    std::string_view name;
    int default_duration_minutes = 0;   // 每类型一个常量，不受状态调制
};
```

**没有强度、方式、时长选择等任何连续参数。** 动作时长是 `default_duration_minutes` 常量，不是 agent 的决策变量。

### 1.3 修正后的判定

| | Rabin 的例子 | 我们的实现 | 判定 |
|---|---|---|---|
| 词汇规模 | 2 个音效 + 4 个动画 | 16 个动作类型 | 我们大 4 倍，**量级不同** |
| 是否封闭 | 是 | **是** | **性质相同** |
| 是否有连续维度 | 无 | **无** | **性质相同** |

**修正：Gap 1a 在本项目「部分成立」。**

Rabin 的论点（内部状态的细微差别传不出去）在我们的 16 项枚举上**依然成立**——只是限制比 4 个动画宽松。说「词汇近乎无限」是把**未来可能的文本化版本**当成了**现在这个系统**。

> 这是我**用设计意图替代了实现事实**。项目确实可能将来走文本，但审核要以 `ActionType` 枚举为准，不以意图为准。

### 1.4 但「部分成立」有精确边界，而且这条边界正好说明为什么主指标必须是留一预测

关键在于 **Gap 3 攻击的是「已实现的行为」（一个动画、一段语音），不是「行为的概率分布」**。

| 评测目标 | 表达容量 | Gap 3 是否成立 |
|---|---|---|
| 实际发生的那**一个**动作（16 选 1） | log₂16 = 4 bits 上限 | **成立** |
| π(A) 的**完整分布**（15 维连续向量，和为 1） | 连续 | **不成立** |

而我们的留一预测，ground truth 是**实际发生的那一个动作**——所以是 16 选 1，**Gap 1a 成立**。

**这不致命，但有一个直接后果（见 §3）**：可测的效应量存在硬上限。

## §2. 【最尖锐】Q01 在当前动作集下**不可检验**

### 2.1 Q01 要检验什么

Q01（分段逆映射）的核心是用户原话里的「**量变引起质变**」：数值上的连续增减，在跨越分段边界后，消费函数（行为）产生**不同性质的响应**。

### 2.2 为什么当前实现测不出来

「量变引起质变」需要一个**能被观察的「变」**。但在 16 项枚举下：

- 「心不在焉地学」→ `StudyAtDesk`
- 「专注地学」→ `StudyAtDesk`
- 「咬牙硬撑地学」→ `StudyAtDesk`

**三者不可区分。** 状态带不同，行为标签相同，任何基于行为序列的评测（包括留一预测、N-gram 对照、ΔNLL）**都看不到差异**。

任务进度（`task_effort_gained`）确实有变化，但它来自 `world.settle()` 的**世界结算**，带 `settlement_variation`（世界噪声），**不是 agent 的决策输出**。用它当 Q01 的观测量，等于把世界噪声当成行为质变——这正是 `前台问题与候选创新.md:58` 警告的「手写规则按自己规定的方向变化，只证明接口接通」。

### 2.3 这条不是「推迟决定」，是「实验条件尚未建立」

用户此前的指示是「先不拍板，再调查调查」。现在可以更精确地说：

> **Q01 不该拍板，不是因为资料不够，是因为拍板所需的实验条件还没建好。** 在动作集获得连续/分级维度之前，任何拍板都无法被检验，拍了也只能记在账上等。

### 2.4 要检验 Q01，必须先做的三选一

| 方案 | 做法 | 代价 |
|---|---|---|
| **(a) 动作加参数维度** | `ActionType` 保留，增加 `intensity ∈ [0,1]` 或离散档位，agent 决策时同时选类型与强度 | 动作空间从 16 → 16×K，N-gram 基线的 E 随之扩大 |
| **(b) 动作标签分级化** | 把 `StudyAtDesk` 拆成 `StudyHalfhearted` / `StudyFocused` 等 | 词汇表膨胀，但保持离散可控；**与 N-gram 基线最兼容** |
| **(c) 承认当前只能验证粗粒度机制** | 明确写「v0 只检验类型级选择，Q01 的段内质变不在射程内」 | 最省事，但等于把用户最初的核心想法推到下个版本 |

**后续状态**：用户已拍板并在工作区实现 (b)。核对发现旧枚举实际是 15 个动作加 `Count` 哨兵；拆分后为 16 个实际动作，不是 16→17。具体实现证据见[当前实现进度](当前实现进度.md)。

## §3. 【有必然失败风险】ΔNLL 阈值必须与动作集规模挂钩

### 3.1 问题

我们预先写定的判定阈值是 **ΔNLL**。但在 16 个动作下：

- 均匀随机基线的 NLL = ln(16) ≈ **2.77 nats**（≈ 4 bits）
- `ln(16)` 是在固定 16 选一、均匀随机猜测时的基准 NLL；它**不是 NLL 上限**，真实动作概率趋近 0 时 NLL 可无界增大
- 实际场景是**强周期性的日常作息**（睡、吃、学、休息），N-gram 很可能轻松做到 0.5–1.0 nats

**因此不能按「文本/大词表」的直觉直接设 ΔNLL > 0.5 或 1.0。** 阈值必须参照实际候选集、强基线和预注册的报告口径；这不是“总跨度只有 2.77”，而是避免把不同难度的选择题混在一起。

### 3.2 修正要求

阈值必须做**归一化**，三选一，且**在看到结果之前**写定：

1. **相对随机基线量尺**：同时报告 `NLL / ln(|A^O|)`，并按 `|A^O|` 分层；它说明相对于均匀随机的比例，不能取代强基线
2. **bits 制 + 对照 N-gram**：报告 Δbits，并要求显著优于 N=1..5 的 N-gram 最优值（而不是对照随机）
3. **困惑度比**：perplexity 之比，避免绝对量带来的直觉误差

**推荐 2**：因为 §5.1 会说明 N-gram 在我们的数据上可能非常强，拿随机当对照是自欺。

### 3.3 连带：动作集规模本身要写进问题卡

T13 的问题卡里必须显式记录全局动作空间和每步 `|A^O|` 的候选规则。**换动作集或候选规则 = 换实验**；不同支撑集大小下的原始 NLL 不可直接混比。若 `|A^O|=1`，随机基线为 0，归一化需单列而非除以 0。

## §4. 整合系统特有的三条新风险（此前没人提过）

以下三条**只在"整合"之后才出现**，单看任何单个模块都看不出来。这是对用户「整合系统」论点最实质的回应。

### 4.1 风险一：串联误差累积，且**失败时不可定位**

机制链 `W → O → X → S → D → π(A) → W′` 是**串联**的。其中 `X` 计划由 LLM 承担（用户已明确的路线）。

单模块各自正确，端到端未必正确。**而"留一预测"测的是端到端结果。**

后果：**R01 一旦失败，无法判断是 `X` 的语义抽取错了、`U_k` 的动力学错了、还是 `π` 的效用函数错了。**

> **对策（建议入 TODO）**：除端到端 NLL 外，增设**分层诊断指标**——
> - `X` 层：同一观测多次抽取的一致性（LLM 抖动测量）
> - `S` 层：状态轨迹的分段平滑性与理论预期方向的符合度
> - `π` 层：给定 `S` 后分布的重现性
>
> 否则失败时会陷入"整体不行，但不知道哪里不行"。

### 4.2 风险二：`X` 由 LLM 承担 → 归因陷阱被整合放大

此前记的归因陷阱是：「若 LLM 做 appraisal，S 打赢 raw history 可能来自 LLM 的世界知识先验，而非机制」。

**整合视角下的新问题**：这个先验不只污染 `X`，它会顺着 `X → S → π` 一路传导，并且**在 `π` 层被包装成"角色决策"**。

即：**你看到的"角色做出合理选择"，可能从头到尾都是 LLM 的常识在起作用，机制链只是个漂亮的过道。**

> **对策**：等维度非理论对照（此前已记）是必要的，但**不够**。还需要一个更狠的对照——**打乱 `S` 的对照**：保持 `X` 与 `π` 不变，把 `S` 随机置换（或换成另一角色的 `S`）。若 NLL 不显著变差，说明 `S` 在这条链上没起作用，**无论它本身多"正确"**。
>
> 这个对照成本很低（只置换一个变量），但杀伤力最大。建议优先加入。

### 4.3 风险三：`S` 的时序惯性与留一预测的耦合

`S` 的各字段有自己的动力学 `U_k`，其中**情绪惯性 / 压力恢复速率**是 `P`（人格参数）的一部分，意味着 `S` 是**带记忆的**。

而 N-gram 的记忆是**显式且短**（N 步）。

这造成一个**不对称**：`S` 的长期记忆是"免费"的（藏在状态里），N-gram 的长期记忆要付参数代价。

- **这本身是好事**——正是「长程 O(1) 可用性」这条信息优势路径。
- **但它也是一个陷阱**：如果 `S` 打赢 N-gram 只是因为"它有无限长记忆而 N-gram 只有 N 步"，那我们证明的是**状态压缩有效**，不是**心理学理论有效**。

> **对策**：增设**等记忆对照**——给 N-gram 足够大的 N（或用 LSTM/SSM 等非理论序列模型），使其在记忆长度上不落下风。只有在**记忆容量相当**的前提下 `S` 仍胜出，才能归因于理论结构而非状态压缩。

## §5. 关于 N-gram 基线的一个非显然判断

### 5.1 它在我们的数据上可能**强得超预期**

16 个事件类型（`E=16`），场景是**强周期性的日常作息**。N-gram 在周期性序列上表现极好——`N=5` 几乎能记住"起床→洗漱→早餐→学习→午餐"这类固定模式。

**所以 N-gram 不是个软基线，它是个硬基线。**

### 5.2 这反而是好事——但要正确解读

- 若 `S` 打赢硬 N-gram → 强证据，含金量高。
- 若 `S` 打平或输给 N-gram → **不是"心理学没用"，而是"当前场景（日常作息）的可预测性主要来自日程结构，不来自内部状态"**。

第二种情况下的正确做法不是放弃 `S`，而是**换场景**——设计一个**日程结构弱、内部状态主导**的场景（例如：突发事件打断、多重动机冲突、信息不对称下做判断）。日常作息场景本身就在 §5.1 的意义上"太容易了"。

> **建议入 TODO**：主评测场景应当**主动削弱日程周期性**，否则整个实验可能只是在比谁更会记时间表。
