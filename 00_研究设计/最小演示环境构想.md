# 最小演示环境构想：单角色 Character Dynamics Lab

记录日期：2026-09-02  
状态：**W→O 场所过滤演示底座已开始实现；具体状态机制、动作策略与实验数据仍待定。**

## 目的

先做一个“小环境 + 一个人”的可回放 demo。它同时承担两种职责：

1. **实验装置**：受控地产生 `W/O/StateDelta/S/action` 轨迹，比较状态更新方法、基线、干预与消融；
2. **公开演示**：在实验稳定后，以最小可复现仓库展示“同一角色因经历与状态不同而做出不同微行为”。

它不是完整游戏，也不以做地图、UI 或多 NPC 社会模拟为第一目标。

## v0 场景边界

```text
一个房间
一个角色 A
少量对象：门、椅子/床、手机、桌子
可选外部事件：B 的消息/未回复、室友提问、时间流逝、门外动静
```

`W` 保存对象状态、位置、时间、事件与动作合法性；角色只接收 `O` 中允许看见或收到的信息。角色并不直接改世界，而是从 affordance provider 给出的合法动作中产生分布，再由 world executor 结算。

当前实现入口：[demo/](../demo/)；它明确将**场所**作为 W→O 的第一版过滤器：A 在某场所时，该场所可观察字段整体刷新进 `O_A`；离开场所后，对应 O 视图保留并随时间成为 `stale` 或 `unknown`。这只是可视化/接口演示，不能误作心理状态更新机制已经实现。

## v0 动作集（候选，待冻结）

```text
close_door / leave_door_open
sit_bed / sit_chair / stand
look_phone / put_down_phone
reply_B / do_not_reply
talk_roommate / remain_silent
leave_room
```

动作以可执行、可验证的微行为为主；是否加入 B、室友作为可行动角色，留到单角色闭环稳定后再决定。

## 实验要回答什么

同一终局、不同历史或可知信息时，比较：

```text
persona only
persona + raw history
persona + summary
persona + Character State v0
```

观察真实/预设目标动作的排序与概率、干预后的分布方向，以及关闭某个 state module/operator 后的变化。demo 的场景脚本和随机种子必须固定，以便不同版本可重放。

## 建议的最小运行模式

```text
Replay mode
固定事件 trace → 更新状态 → 输出各动作概率 → 与 trace 中目标动作比较

Intervention mode
复制同一终局 → 只改一段历史或观察 mask → 对比 state/action distribution

Simulation mode（后置）
按分布采样动作 → world executor 结算 → 继续下一 tick
```

## GitHub 成熟条件

在公开前至少具备：

- 清晰 README：研究问题、世界/观察/状态/动作职责与不做什么；
- 一个无需 API key 也能回放的 fixture trace 和基线；
- 配置化 module/operator/ablation；
- 每次运行产生可读日志与可比较结果；
- 不把任何未验证的“心理学正确性”或新颖性写成事实。

初期可先本地开发；仓库公开是实验可复现后的交付，不是当前阻塞项。
