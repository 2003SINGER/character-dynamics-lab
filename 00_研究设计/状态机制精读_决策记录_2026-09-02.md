## 这轮实际收束的不是“多加模块”

核心链从此前的 `W → O → ΔS → S → π(A)` 细化为：

```text
W ── SceneFilter ── PerceptionFilter ──> ΔO / O
ΔO + O + old S + P ── semantic interpretation ──> X
X + old S + Δt + P ── typed dynamics ──> S
O + S + P ── transient decision context ──> D ──> π(A^char)
A^char ── expands to world primitives ──> W'
```

这仍只服务课题锚：在受限信息下维护对未来角色行为有用的状态，并检验它是否改善条件行为分布；不是新增一个独立的 appraisal、世界模型或游戏引擎课题。

## 用户已明确认可的机制决定

### 1. `X` 是事件意义，不是直接的数值状态改写

`X` 是对 `ΔO` 的结构化解释/Appraisal，例如目标相关性、目标一致性、可控性、意外性、不确定性或社会拒绝线索。开放语义解释可由 LLM 候选承担；`X → S` 则应由明确、可替换的动力学算子承担。这样允许新证据触发 re-appraisal，而不是把 LLM 的自然语言判断直接写成情绪数值。

### 2. `S` 是 typed fields；时间尺度属于字段动力学

不再以“快/中/慢”硬分层所有状态。每个字段应自己定义：触发、累积/恢复/衰减、饱和、重评估、值域和 `P` 的调制，例如：

\[
s^k_{t+1}=U_k(s^k_t,X_t,\Delta t;\theta_k(P)).
\]

候选字段不是最终本体论；只有跨时间保存且能改善未来行为预测/干预判断的量才进入 `S`。

### 3. `Goal` 与 `Intention` 分开；可迁移的维护模式

`Goal` 是候选目标和竞争，`Intention` 是已承诺的近期行动方向。后者必须具有 commitment、reconsideration、termination 和 failure 条件，不能每轮随刺激重置。更一般的可迁移模式是：

```text
Candidate → Selection → Commitment → Reconsideration
```

它可用于解释、目标和 belief revision，但何处实际采用需随 v0 实验收缩。

### 4. `P` 是响应函数的参数；v0 固定

`P` 可表示敏感度、惯性、恢复率、阈值、行为偏置、压力下噪声等；参数可以用阈值/饱和/平滑反转函数调制，而不只是线性权重。用户保留了“长期行为—世界后果—状态轨迹可慢慢反馈到 P”的后续想法，但 v0 明确固定：`P_{t+1}=P_t`。

### 5. `D` 是本轮决策上下文，不自动扩张 `S`

如 `effective_caution`、decision noise、planning depth、hesitation 等可由 `O,S,P` 临时计算，决策完成即消失。进入 `S` 的门槛是：需要跨时间保存、且对后续行为仍有预测价值。

### 6. 关系是有向、稀疏的角色关联状态；不进单人 v0

多角色时，`A → B` 与 `B → A` 应是不同的数值/类型化关系状态（如信任、亲近、怨恨、关系类型），而不是大段自然语言或无向“关系真值”。它可以为了存储和查询放在 runtime 的中央有向图中，但语义归属是角色侧的 `R_i[j]`，不是 `W` 的上帝视角心理事实。单角色小环境先不做这一层。

### 7. `Scene` 是局部世界与动作的共同边界

`Scene` 先截取角色所在场所的候选变化，再由视野、听觉、注意力、遮挡等 PerceptionFilter 决定是否写入 `O`：

```text
W → SceneFilter → PerceptionFilter → O
```

同一 `Scene` 也解析此刻世界真实允许的动作集合 `A^W`。对象提供基础 affordance；场景可注册少量人为设计的、具有行为意义的组合动作。`A^O` 是角色依据其 `O` 知道/想到的可选动作，不得泄漏 `A^W` 的未知条件。

### 8. 人物动作与世界原子操作分离

`A^char = 上床玩手机` 可以与“看消息”“关门”等同为角色决策候选，而不要求人物动力学在走路、拿物、躺下等每个世界原子步骤间重新决策：

\[
A^{char}\rightarrow[a^{world}_1,a^{world}_2,\ldots]\rightarrow W'.
\]

第一版可手写少量高质量的对象动作和场景组合动作；不把无限动作自动组合当目标。

## v0 的明确停止线

- 单角色、一个小房间/场所；有限对象、外部事件和行为集；
- 固定 `P`，无 persona-drift critic/PCC/PDS、无 P 学习；
- 无复杂多角色关系、ToM、开放世界或无限动作生成；
- 演示环境首先是可回放、可干预的实验床；后续才可整理为展示或现代 C++ 学习项目；本对话不据此开始编码。

## 继续精读时必须解决的四个计算问题

1. `X` 的最小 schema 是哪些变量，哪些仅为候选？
2. 每类 `U_k` 如何实现触发、恢复、累积、边界和 re-appraisal？
3. `P` 以何种参数进入这些更新器和策略？
4. goal/intention 的 activation、commitment 与 reconsideration 怎样可判定地运行？

每个答案必须回连到：输入、状态、更新、P 的位置、action 接口，以及预测/干预/消融能否检验其收益。
