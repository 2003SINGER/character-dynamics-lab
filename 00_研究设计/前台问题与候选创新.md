# 角色动力学实验室：前台问题与候选创新

更新时间：2026-09-02  
状态：**机制接口已完成第一轮收束；具体计算、文献归因、研究缺口和效果均未验证。现有文献库是定向种子库，不是系统综述，不能据此排除“已有工作已覆盖完整问题”。**

## 这一项目在研究什么

本项目要做的是一套**前向角色动力学模型**：人物只能接触局部、延迟且可能不完整的信息；其经历在持续状态中留下可计算后果；模型先给出这个人物此刻可能行为的条件分布。已有叙事的下一真实行为可检验该分布；开放运行时，同一分布可用于选择 NPC 行为或给作者提供角色行为参考。这三种用途共享同一个前向机制，不能彼此替代。

候选总问题：

> 在给定人物此前经历及其当下实际可知世界的条件下，怎样的状态表示与更新机制，才能形成可预测、可干预检验的动态行为规律？

这不是“完整游戏”“统一心理学模型”或“长期用户画像”项目。`W/O/S/P` 也不是要作为论文中另起一套新架构来宣称；它是避免 `人物设定 + 整段历史 → LLM 猜行为` 的持续计算中间层。回放给出硬验证，开放 NPC 是同一模型的生成运行方式；两者都保留，但第一阶段不能把工程规模当成研究结论。

### 课题锚与防漂移规则（用户于 2026-09-02 确认）

课题锚不是“研究 W/O/S/P”，而是：

> **在受限信息下，持续更新的角色状态能否保留历史中对未来行为有用的后果，并据此产生更可检验的行为分布？**

机制演化只要在补这条链，就是深入；若一个想法本身有趣却不直接改善“维护行为相关状态”或“由状态预测/生成行为”，则移入后续分支。v0 先固定 P，限定 W/O、S 和动作集合；P 的可塑性、多角色社会动力学、完整 Galgame 抽取、开放世界平台和专门模型训练均不作为第一阶段前置条件。

### 已确认的核心边界：两个不同性质的状态系统

用户确认的中心不是泛化的“数据随时间变化”，而是受限接口下的**权威故事世界、人物世界视图、人物自身状态与长期参数**如何各自更新、再相互作用：

\[
W_{t+1}=G(W_t,A_t,E_t,\Delta t),\qquad O_{t+1}^i=M_i(O_t^i,W_{t+1},\text{information access})
\]
\[
X_t^i=I(\Delta O_t^i,O_t^i,S_t^i;P_i),\qquad s_{t+1}^{i,k}=U_k(s_t^{i,k},X_t^i,\Delta t;\theta_k(P_i)),\qquad D_t^i=H(O_t^i,S_t^i,P_i),\qquad \pi_t^i(A)=G(O_t^i,S_t^i,D_t^i;P_i)
\]

其中 `W` 是权威的、可执行的故事世界：对象、人物身体状态、剧情事实、时间、affordance 与因果结算都在这里。`O_i` 是角色 i 持续维护的一份局部世界模型，尽量与 W 同构，允许旧值、`unknown`、来源和置信度；它保存“i 觉得外面怎样”，而非世界实时真值。`X_i` 是对观测变化的结构化意义/Appraisal；`S_i` 是字段各自带动力学的自身状态；`D_i` 是本轮才计算的决策上下文；`P_i` 是长期响应参数。多角色时，关系可物理存于中央稀疏有向图，但 `A→B` 的亲近/信任/怨恨等语义上是 A 侧关联状态，不是 W 的心理真值；单角色 v0 不做它。研究判断的重点是：这套中间状态能否让既有行为处于合理概率区域，并在历史或可知信息干预下给出方向合理的变化，而不是把任意 evolving stream 都归为项目近邻。

### 已确认的运行边界

```text
W ── SceneFilter ── PerceptionFilter ──> O
ΔO + O + 旧 S + P ──语义解释/Appraisal──> X ──字段动力学──> S
O + S + P ──本轮 D──> {候选人物动作、概率/排名} ──选择/采样──> A^char ──原子结算──> W'
```

- `O` 的基础维护不应默认用 LLM：新数据流入时更新；环境暴露时复制相关 W 字段；其余字段可保留旧值、降低置信度或变为“角色知道自己不知道”。LLM 只可作为复杂观察含义/关系估计的候选推断器。
- `Scene` 同时是观察候选流的局部边界和 `A^W` 的生成边界；对象给基础 affordance，场景可给有限组合动作。感知过滤后才写入 O，未知条件不能进入 `A^O`。
- 行为运行时，模型应先产生候选与偏好，并可由模型选取或程序在高分候选中采样；人物动作 `A^char` 可展开为多个世界原子操作，W 的规则/affordance 拥有最终合法性校验权。
- 回放评分在输出 `π(A)` 处停止，随后才将外部真实行为 `A*` 映射到同一动作接口比较；它不能倒过来充当自主循环的输入解析。

## 必须保持的分层

```text
研究框架
主客观隔离 + 历史驱动状态 + 条件行为分布 + 可替换数据流

待研究机制
状态表示 / 状态更新 / 心理约束 / 记忆与恢复 / 决策不确定性

实现选择
变量名称、公式、JSON 协议、LLM / rule / hybrid / learned 的具体实现
```

因此，数据流架构、任何 appraisal 变量或某个心理学理论都不是已定方法或创新。

### 数据流在本项目中的位置

数据流是实施与审计状态更新的设计语言，不是默认的论文贡献：

\[
W\rightarrow\text{observation/information stream}\rightarrow O_i\rightarrow\text{StateDelta/update operators}\rightarrow S_i\rightarrow\pi(A\mid\mathcal A_t)
\]

它要求事件只更新受影响的状态成分，并保留 event → delta → state/action 的 provenance；这样才能替换某个 operator、断开它做消融、改写一段历史重放干预、以及表达快/中/慢变量的不同时间尺度。真正需要验证的仍是 state/update mechanism 是否改善行为预测、校准与干预响应，而不是“使用了数据流/DAG”。

### 与 task-oriented Agent 的关系

本项目仍属于 Agent/interactive character 的范围，但它不以外部任务完成率作为每一步 policy 的唯一语义。task agent 常围绕目标、工具结果与 task progress 选择行动；Character Dynamics 关注在可执行动作集合内，稳定背景、动态状态与局部观察如何形成“此刻这个角色更可能做什么”的条件分布。两者共享 `observe → state → decide → act → observe` 的一般闭环，区别在状态语义、动作空间与评价（任务效用 vs. 行为预测/校准/一致性）。这不是“传统 Agent 没做过”的新颖性主张，而是项目的应用定位。

## 值得继续核验的候选创新

### 方法本体与验证尺子必须分开

“回放历史、预测下一真实行为”是检验协议，不是方法本体。当前应按计算职责而非论文中是否出现 `world/state/belief/action` 这些名词来比较：

\[
W\xrightarrow{\text{observation mask}}O_i,
\quad (P,S_t,O_i)\xrightarrow{\text{state / policy}}P(A\mid\mathcal A_t),
\quad A^*\xrightarrow{\text{revision}}S_t'
\]

其中 `P` 是长期响应参数，`S_t` 是人物自身的动态状态，`\mathcal A_t` 是世界此刻真正可执行的动作集合。方法问题在于：观察变化如何成为 `StateDelta`，P 如何调制状态转移、长期维持与同一状态的行为表现，状态如何使动作分布可测地变化，以及真实行为如何作为评测接口而非运行时上帝信息。不能再把整条链压缩为 `history → next action` 后仅凭任务名称查重。

### P/S 的当前边界（已确认；具体算法未定）

`S` 不等于情绪集合。它只要是“人物自身、当前仍会变化、且对未来行为有预测作用”的状态即可；第一版可按功能与时间尺度审计为慢性状态、目标/动机、即时情绪与认知/身体状态、临近行为的决策状态。是否保留某个指标须看预测价值，不以重建完整心理学为目标。

`P` 不是人物小传，也不应直接写成固定行为脚本。它是反应函数/阈值/敏感度/惯性/随机性等长期参数：P 调制 `O → S`、状态衰减与累积，并以 `G(O,S;θ(P))` 的方式调制行为选择。用户提出保留两条**待验证的 P 可塑性候选**：长期反复的 S/行为模式经巩固后缓慢影响相应 P；或单次事件先造成异常强的 S 改变，只有溢出预定义阈值后才允许部分沉淀进 P。不得在文献与实验前把它们写成既定心理规律或固定公式。

### A. 条件行为分布一致性

人物一致不等于每次选择相同行动，而是 `P(action | subjective state, observation)` 及其不确定性应与人物历史、目标冲突、习惯和信息充分性相称。研究上可问：模型能否不仅预测行为，还预测人物何时应稳定、何时应分散？

### B. 干预式动态一致性

不是只问输出“像不像人物”，而是分别干预历史、可知信息或一个客观事实，检验行为分布的变化方向和幅度。该项必须同现有连续行为预测、persona 评测、ToM/partial-observability 文献严格查重后，才能声明为贡献。

### C. 面向未来行为的 Predictive Subjective State

状态不是 history summary；目标是保留历史对未来行为仍有预测价值的痕迹。可与 raw history、摘要记忆、显式状态等在相同信息预算下比较预测、干预响应、长期轨迹与无关历史干扰。

### C-2. 效率—效果与可控性前沿（已采纳为第二评价维度；不是主创新声明）

除预测质量外，项目还应问：在 `NLL(state) ≤ NLL(baseline) + ε` 或其他预先冻结的质量容差下，哪种状态表示需要更少的上下文和运行成本？这是一条**部署/系统评价线**，不替代“状态是否保留有用历史后果”的主检验，也不能在主检验无效时被包装成心理机制收益。

公平 baseline 至少包括 raw history、强 summary 与 Character State，不可只赢 raw history。候选记录项为：单次输入/输出 token、调用频率、P50/P95 决策延迟、单位决策成本、长轨迹吞吐量和随 NPC 数量增长的扩展性；另行记录结构化状态带来的存档/回放、局部干预、信息权限、跨模型迁移与 provenance 调试能力。若 summary 在质量、成本和可控性上均不差，应承认更简单方案更合适。

可能的工程实现是分层运行：高频 W/O/时间推进由程序维护，常规候选过滤和轻量 policy 不必调用 LLM，只有开放语义 appraisal、复杂目标冲突或关键对话按事件触发 LLM。这是待实现和待测的 deployment hypothesis，不是 v0 已经证明的系统收益。

### D. LLM 自由状态更新的过冲/漂移

先验证现象：轻微事件是否引发不成比例的状态跳变、负面叙事自强化、恢复缺失或不恰当路径依赖。若现象可稳定复现，受约束状态转移才成为有明确目标的方法候选。

### E. 动态不确定性与三类随机性

客观世界随机性、主观解释不确定性和决策随机性不可混成固定 temperature。候选诊断是：世界约束强且人物目标明确时分布应收缩；冲突、信息不足或多目标竞争时可能扩散。该项目前更适合作为 A/B 的诊断维度。

### F. 预测贡献驱动的历史保留（跨域启发）

来自 SyncStream 的 `project hypothesis`：历史成分是否保留，不应只按时间衰减，而可由其对当前/未来行为预测或干预响应的贡献决定。它不是把 concept drift 直接套到人物上，也不是既定 state update；只有在与 recency、raw history、summary 等对照后，才可能成为可检验的状态维护问题。

## 当前不应声称

- 任何明确的文献 gap、首创性、可发表性或方法收益；原始对话中的论文名、结果与比较必须回到原文核验。
- “没有在当前库中看到完整同题工作”不等于“世界上没有人做过”。当前检索尚未按可复现检索式系统覆盖 ACL Anthology、IEEE Xplore、ACM DL、Springer、AAAI、IJCAI、NeurIPS/ICLR、CogSci、AAMAS、心理学与计算社会科学数据库，也未完成引文追溯；因此它**不能**支持任何新颖性或拥挤度结论。
- 某种心理学状态变量、appraisal 规则或 LLM/规则混合方案是正确的。
- 小说中低概率行为即可被判定为“人物写崩”；它也可能暴露状态遗漏、信息遮罩错误或尚未建模的转折。
- 已拥有数据集、代码、实验结果或可运行 NPC 系统。

## 文献审计后的直接约束

`paper evidence`：连续行为预测、动态 persona、多时间尺度状态、文本世界轨迹、时间化角色 belief、长程漂移和叙事承诺均已有直接近邻。详细边界见 [全量近邻精读总表](../01_文献/全量近邻精读总表_2026-09-01.md)。

`外部定向检索（2026-09-01；2026-09-02 语义校正）`：不能把抽象闭环本身当作空白，但也不能把不同职责的 `world` 直接视为等价。PsychSim 的强项是 factored ground-truth decision state、agent belief 与 preference 驱动的决策，以及有限的行为—mental-model revision；它并不因此完整覆盖对象化可执行 `W → O_i → S_i` 的职责分层。Generative Agents 更接近独立 sandbox、对象状态与局部观察，但其人物侧主要是 memory retrieval/reflection/planning，而非经行为预测验证的动态主观状态。FAtiMA/EMA 强在外部事件如何经 belief/memory/appraisal/affect 进入人物行为，且可与外部游戏引擎相接；BDI 强在 belief/desire/intention 到叙事行动。DYNToM 与 PersonaArena 分别是连续心智轨迹/合理性与动态角色评测的直接近邻。每篇只应按其实际计算职责占位，不能据此声称已用同一世界语义、状态更新、动作空间或评测实现了本项目。

`project decision`：在各功能部件与抽象闭环层面已有大量直接近邻；但“对象化可执行世界—受限观察—性格调制的状态动力学—affordance 条件下的微行为策略—行为反馈状态修正”这条具体计算链尚未逐篇完成职责级查重。因此目前既不能把架构重述当创新，也不能用“PsychSim 已做 world/state/belief/action”一类名词匹配把该方法空间判死。是否还有可发表问题，只能落在一个被严格界定、可复现实验的机制与缺口（例如状态充分性、信息干预、预测校准、叙事控制、在线状态修正），且必须在系统查新后才可判断。

`project decision`：第一阶段不主张“提出动态角色系统”，而检验历史/信息干预下的条件行为分布、状态预测充分性与动态不确定性；叙事 framing 和角色身份泄漏必须成为实验控制项。

## 当前最小的启动动作

若用户明确启动，先写一张**问题卡**，只确定：

1. 一个极小、可回放的对象世界与有限 affordance 行为集；
2. 一条角色可见信息遮罩；
3. 一张机制卡：`StateDelta` 如何产生、`P` 如何调制状态与行为、`S` 怎样进入动作策略、真实行为如何反向修正状态；
4. 一个干预对（如同一终局、不同历史，或同一世界、不同可知信息）；
5. 两个最朴素基线：raw history 与强 summary/history state；
6. 一项主结果：正确行为的排序/概率，或受控干预下预先定义的分布变化；
7. 一项第二指标：在质量容差内的 token、调用次数、延迟或成本，并标明测量环境。

若这张问题卡无法写出，继续扩展机制或世界都没有意义。

## 当前推进路线（用户于 2026-09-02 确认）

第一优先不是继续泛查“像不像的 Agent”，而是职责级精读**状态更新机制**：每篇都记录 `事件/观察输入 → 状态表示 → 更新规则 → 性格参与位置 → 状态如何进入 action`。重点从 FAtiMA、EMA、Dynamic Persona Coherence 及其引文链扩展到 affective computing、belief/goal dynamics 与 interactive narrative；心理学在此是状态变量和更新约束的来源，不是本项目对人类心理规律的宣称。

并行开一条**动态隐状态跟踪**检索线：intent/goal tracking、dialogue state tracking、dynamic user modeling、preference drift、concept drift/change detection、belief/state estimation。它们与角色任务不同，但共同处理“连续证据怎样稳定更新不可直接观察、又会变化的状态”；只能作为方法来源，不可把用户意图与角色心理直接视为同一状态。

但机制阅读、`Character State v0` 设计和最小实验闭环必须并行，不能先闭门“完善”数月。当前迭代路线为：

```text
机制文献卡 + v0 状态设计
             ↓
最小 W/O/affordance 任务 + persona/raw-history/summary/v0-state 基线
             ↓
小实验与粗消融，定位丢失信息或无效模块
             ↓
回到相关工作与机制，形成 v1/v2
             ↓
扩大轨迹与正式比较/消融；NPC demo 仅作为后续应用
```

这允许完整 prototype 先较丰富，再由比较和消融删减、合并或重写模块；最终论文方法必须围绕一个可证伪的主张，而不是把模块数量当贡献。

原型编码时遵循 [低耦合与消融接口原则](原型实现与消融接口原则.md)：状态/更新器/policy 输入必须有明确中性语义、关闭路径与 provenance，不能仅因一个变量数值恰为 `0` 就误判其影响已被消除。

第一版实验载体已确定为[单角色最小演示环境](最小演示环境构想.md)：一个小环境、一个角色、有限对象和微行为。它先是可回放/可干预的实验装置，实验稳定后可整理为 GitHub demo；不应先扩成完整游戏或多 NPC 系统。
