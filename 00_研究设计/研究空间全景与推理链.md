## 0. 已确认的母题（不是创新主张）

人物不是静态 persona，而是只接触局部世界、随历史变化、输出概率行为，并通过自己的行动重新改变世界的动态系统：

```text
World fact W ──perception filter──> observation Oᵢ
                                      │
                                  interpretation / belief
                                      │
history + Oᵢ ──> subjective state Sᵢ ──> P(action Aᵢ)
                                      │            │
                                      └── action ──┴──> world consequence W'
```

关键界限不是变量名，而是信息边界：`world fact ≠ observation ≠ interpretation/belief`。例如“B 三小时未回复”可为客观记录；“B 在躲 A”只能是 A 的解释，不能反写成世界事实。

## 1. 不是一个课题，而是一组相连的问题

### 1.1 行为一致性应是条件分布，而非固定反应

要问的不是一个单一动作“像不像人物”，而是：

\[
P(A_t\mid S_t,O_t), \qquad H\big(P(A_t\mid S_t,O_t)\big)
\]

是否与历史、目标冲突、习惯和信息充分性相称。同一低概率行为在平静重复日常中可能异常，在重大冲突或信息不足时却可能合理，因为整个分布本应更分散。这里保留“随机性本身也需要一致”的直觉；它尚不是已证实的新评价理论。

### 1.2 评测应看受控改变后的变化，而不只看一次输出

对同一世界换人物、对同一人物换历史、只改变一个可见/不可见事实，观察：

\[
do(X=x_1)\;vs\;do(X=x_2)\quad\Rightarrow\quad\Delta P(A)
\]

例如 B 持续帮助 A 与持续欺骗 A 两段历史，在“B 请求帮助”的相同终局下，应产生可预先说明方向的行动分布变化。这里的核心不是“用了 intervention 一词”，而是把角色一致性变成可证伪的行为实验。现有 ToM、角色评测、因果/反事实评测可能已覆盖其中一部分，须逐项查证。

### 1.3 状态应为未来行为保留历史后果，而非漂亮摘要

\[
H_{\leq t}\rightarrow S_t,\qquad
P(A_{t+1}\mid H_{\leq t},W_t)\approx P(A_{t+1}\mid S_t,W_t)
\]

这里的意图是让 `S_t` 保存“过去在此刻这个人身上留下什么”，而非完整保存事件清单。它必须与 raw history、摘要记忆及手工/学习状态在相同信息预算下比较，不能凭状态字段看起来心理学化就成立。

### 1.4 先研究 failure mode，再谈心理学约束

待检验现象是 LLM 是否把轻微事件逐轮解释得更负面，形成过冲、单调负向漂移、恢复缺失或过强路径依赖：

\[
S_t\rightarrow \operatorname{Interpret}(E_t\mid S_t)\rightarrow S_{t+1}
\]

如果现象稳定，状态惯性、恢复、饱和或其他转移约束才有明确的因果目标；若现象不存在，预设 appraisal update operator 也不应被硬塞进来。

### 1.5 状态动力学不是统一即时加减

应保留快—中—慢变化的假设空间：emotion 可快变快复原，stress 可累积慢退，trust 可慢建而遇背叛骤降，habit/trait 变化更慢。这是待比较的动力学假设，不是指定 `S=(fast,medium,slow)` 就自动成为方法。

## 2. 你明确提出的两个小问题：Forward 与 Inverse

### 2.1 Forward：状态到下一行为

\[
(S_t,W_t)\rightarrow P(A_{t+1})
\]

在有真实后续的叙事/轨迹中，可用 replay 或 teacher forcing 测试模型是否给真实行动合理的概率或排序；在无真实后续的开放世界中，同一模型可生成 NPC 行为。

### 2.2 Inverse：行为/反馈反推状态

\[
(A_{t+1}^{*},W_t)\rightarrow P(S_t\mid A_{t+1}^{*},W_t)
\]

人物状态不可直接观测：小说中看到的是行动、对话和少量心理描写；现实用户中是点击、选择、回复、评分、编辑。因而可将人物建模与用户建模看作 latent-state estimation 的两个应用表面。

### 2.3 两者的关系

它们不是两套随意拼接的产品：Forward 给状态表征一个预测约束，Inverse 让新行为/反馈修正状态。PsychSim 已是重要直接先例：它有主体 belief、行动选择、以既往观察比较候选 belief 的概率，以及按行为拟合目标权重。故不能将 Forward–Inverse 回路本身主张为新；仍待查的是它在自然叙事/长交互数据上的状态学习、最小充分性、概率校准和干预验证是否已有等价工作。

## 3. Replay 与 simulation 是同一个模型的两种运行方式

```text
真实叙事历史 ── teacher forcing / replay ──> 检验 predictive validity
                                             │
                                      同一 Character Model
                                             │
开放世界运行 ───────────────────────────────> 生成 NPC 行为
```

这不是说“小说一致性检测”和“NPC 生成”已经能合成同一篇论文，而是保留一个工程—研究闭环：前者提供可检验的真实后续，后者是在没有 ground truth 时的部署模式。是否同一表征确实跨两模式有效，是未来实证问题。

## 4. 多主体分支：主观错误可以经由行动变成客观社会事实

一个保留的后期问题是：B 未回复 A（事实）→ A 误以为 B 回避自己（belief）→ A 疏远 B（行动）→ B 感到被疏远并反应（新事实）→ 关系真的恶化。它关心 misunderstanding、self-fulfilling prophecy、trust/reputation dynamics，而不是给 agent 直接加一个 `relationship -= 1` 脚本。这个分支与社会模拟、多智能体建模高度相邻，当前不纳入第一阶段承诺。

## 5. 支持研究、但不是独立创新的骨架

数据流式/typed pipeline、`StateDelta`、事件 provenance、可回放和可替换算子，服务于 ablation、反事实、错误定位。它们是实验可追溯性的工程条件；不能仅因结构清晰就作为研究贡献。

另一个后期分支是从自然语言叙事抽取有限行为世界（对象、状态、affordance、动作）。它可能独立形成信息抽取/世界建模课题，但目前不能默认为主线的免费前处理。

## 6. 已有先例如何改变本图

`paper evidence`：PsychSim、FAtiMA/EMA、BDI 叙事已覆盖主观 belief/情感/目标、动作和世界交互的不同组合；DYNToM 已覆盖连续情境中的 belief–emotion–intention–action 轨迹评测；Dynamic Persona Coherence 与 PersonaArena 已覆盖 LLM 动态 persona、状态更新和行为连贯性评测。

`project consequence`：上图作为**问题空间和检索地图**仍有效，但任何单独节点、整个闭环、或“动态一致性”都不能再被称作当然的创新。只有一个经系统查新后仍成立的窄命题，连同清晰基线、数据、评价和失败条件，才可能成为研究问题。
