# Single Room Runtime Visualizer v0

This is a static viewer for traces generated by the existing Continuous Runtime v1. The browser only renders JSON; it does not reimplement scheduling, appraisal, state updates, policy, or W validation.

Build and generate three deterministic presets from the C++ project:

```sh
cmake -S . -B build -G Ninja
cmake --build build
build/character_dynamics_single_room_demo --scenario deadline --output demo/single_room_v0/traces/deadline.json
build/character_dynamics_single_room_demo --scenario phone --output demo/single_room_v0/traces/phone.json
build/character_dynamics_single_room_demo --scenario commitment --output demo/single_room_v0/traces/commitment.json
cd demo/single_room_v0/web && python3 -m http.server 8000
```

Open `http://localhost:8000`. Presets expose W/O/S, RunningAction, events, gate/policy context, and typed outcomes. The trace is the source of truth; scripted fixture selectors are labeled in the trace and are never presented as psychological claims. The viewer starts in Developer View and the toggle switches to Player View, hiding the W card while retaining actor-visible O/S/time context.
