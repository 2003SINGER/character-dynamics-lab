# AGAIN 时间轴审计

对 raw telemetry 与严格同 `(player_id, session_id, game)` 的 valid=1 annotation 对照后，确认首版“全为 annotation 0”的原因是时间单位不一致，而非 session key 错误：

- telemetry `[control]time_stamp` 为 session-relative seconds（示例范围约 43–166）。
- annotation `[control]time_stamp` 实际为 milliseconds（示例范围 0–125,977）。
- annotation epoch 与 telemetry epoch 还存在约数十至数百秒的记录偏移，不能直接用 epoch 做同轴匹配。
- 将 annotation `time_stamp / 1000` 后，20 条跨 9 游戏 dev session 均能得到非恒定 arousal proxy；按“最新 valid annotation ≤ telemetry time_stamp”匹配，未使用未来值。

因此当前 adapter 只承认 `source_arousal_proxy` 为 annotation-derived proxy；不把它提升为 `source_O`、`state_label` 或动作真值。AGAIN 尚未开放全量 semantic admission。
