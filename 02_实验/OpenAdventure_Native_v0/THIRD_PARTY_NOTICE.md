# Open Adventure evidence attribution

The three `runs/native-*/input.txt` files reproduce short upstream regression
inputs from Open Adventure 1.22, commit
`e6160529e70a8c7a06b9a5f190d69aa35c4c62f5`, at
<https://gitlab.com/esr/open-adventure>. Each retains its upstream copyright
and SPDX notice. `execution_stdin.txt` is the normalized input with a native
quit exchange appended. Game text in `stdout.txt` is recorded output of that
same upstream game. No upstream binary, complete source tree or game-data
bundle is distributed here.
