# Veloren v0.18.0 native capability notes

Scope: read-only review of the official fixed source commit `1d12f35edd6cdbfc1fb921c167cdd7beeeffe248` (GitLab v0.18.0 build), viewed with the complete instrumentation patch `tools/veloren_native_v0/veloren-native-talk.patch` (SHA-256 `4174287ddd467804e7efbfe7bb6868736475597f0225067c2030aaa17c709610`) applied. File paths and Rust line numbers below refer to this patched/instrumented source view, not the unpatched GitLab tree or tag. The capability paths and effects described are existing native gameplay logic; the patch adds the external request/observation interface and does not implement gathering, trade, quests, or persistent social effects. Stable function/field names are included as anchors where line offsets may vary. This is source evidence, not a new runtime result. Actual-run evidence is identified separately.

## What the saved run demonstrates

The no-request baseline provides limited affirmative evidence of ordinary travel: two real NPCs changed position along a native hideout route and later changed Loaded→Simulated. See the [baseline readback](../server_build_20261017/native_baseline_readback.md) and the raw event path in [RESULTS](../../RESULTS.md). In the final interface run, one request traversed the same-ID accepted → native branch → queued Say → Agent `native_speech_emitted` path; a bounded post-window also recorded the sender's native `walk to pirate hideout` / `Goto` activity continuing after the external lease ended ([independent readback](native_run_readback.md)). This is sender-side emission and continued native travel only—not evidence of recipient delivery/acceptance, an NPC-to-NPC exchange, relationship change, quest, trade, or learned fact. Saved traces do not demonstrate trade settlement, hiring, quest completion, gathering, or report/sentiment change.

## Candidate combinations for later planning (not implementation authorization)

1. **Escort quest + travel + deposit/reward:** could support a future constraint such as reaching a destination before a deadline while preserving an agreed resource stake. Measure quest/job, position/site, and inventory state—not conversation text; native dialogue acceptance and all quest preconditions still apply.
2. **Trade + inventory state + site prices:** could support acquiring an item before a later task or preserving scarce stock. Use supported native trade participants; NPC-to-NPC initiation is not established.
3. **Event-derived reports/sentiment + future behavior:** help, damage, theft, or death reports can persist and influence hostility/dialogue/hired behavior. This could support constraints like avoiding a witnessed betrayal or preserving an ally relationship, but only from real events and observed report/sentiment fields; speech alone is not the cause/effect proof.

These are source-grounded candidates, not evidence that a Character Dynamics Planner has organized them, that the paths ran in this world, or that a general action interface exists.
