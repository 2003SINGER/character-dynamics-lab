# Current X/S semantic contract (candidate)

The current six-dimensional X vector is retained for compatibility with the
existing replay transition code. It is not presented as a canonical literature
appraisal schema.

| current X | role in this project | literature status |
|---|---|---|
| `effort_load` | resource/effort cue | engineering input |
| `goal_relevance` | appraisal candidate | term definition and cross-paper meaning require audit |
| `positive_conduciveness` | positive appraisal candidate | literature-motivated; not frozen as a universal dimension |
| `negative_conduciveness` | negative appraisal candidate | literature-motivated; separate channel retained pending audit |
| `social_opportunity` | contextual/social cue | project input, not claimed as a standard appraisal dimension |
| `recovery_cue` | resource/context cue | engineering input motivated by recovery dynamics |

`fatigue` is a project candidate resource/fatigue state affecting the relative
preference for effortful versus recovery-oriented actions, not a medical
diagnosis. `engagement` means broad behavioral involvement in the current
situation and available opportunities; it has no built-in positive valence.
`tension` is a candidate dynamic activation arising from threat, obstruction, or
urgency. Field semantics are project definitions; the relaxation family is
literature-motivated; numerical parameters are learned; predictive validity is
not established.
