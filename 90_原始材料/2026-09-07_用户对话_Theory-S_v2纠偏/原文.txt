4. 修掉当前 transition 公式：现在不是我们原来的 dynamics

当前：

S_next = sigmoid(alpha * S + B X)

则：

也就是说“没有事件”反而会把低状态自动推向 0.5 以上。

这不等于 v1.2 已验证的一阶 relaxation / recovery。

改成真正的一阶 target relaxation：

target_t = g(b + B X_t)

S_t = alpha ⊙ S_{t-1} + (1 - alpha) ⊙ target_t

等价写法也可以：

S_t = S_{t-1} + eta ⊙ (target_t - S_{t-1})

其中：

alpha = 1 - eta

要求：

每个 S field 有自己 alpha_j / eta_j；
b_j 给该字段 neutral equilibrium；
B_j 是该字段自己的 X sensitivity；
g 负责 target bounded；
convex relaxation 保证 S bounded；
neutral event 可以朝 field-specific baseline 回归；
repeated cue 能积累；
cue removal 能产生 residual decay；
recovery cue 能推动对应 target 回落。

这才是把 TCN 一阶松弛 + 我们 v1.2 dynamics 参数化。

每个 state field 自己有 dynamics。
