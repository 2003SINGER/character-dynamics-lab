1. Theory-S 不能是我们拍脑袋的一维 EMA

这个我完全同意。现在这个：

expected effect confirmed → x=1
S_t = EMA(x)

充其量是一个机制探针，不是我们真正想研究的 Theory-S。

正式一点的 Theory-S 应该从已有计算心理学/游戏 agent 文献里选机制，再组合成我们自己的可检验版本，而不是“想到几个心理字段就塞进去”。

几个很直接的来源已经很清楚：

EMA：appraisal 应该是角色对“自己与环境关系”的解释，而不是世界事件直接变情绪；动态性来自 perception / inference / coping 的变化。
MAMID：外部 cues、内部 interpretation、goal、当前 emotion 和稳定 trait 一起参与 appraisal；随后 affective state 进一步影响 action selection、goal selection、attention 等处理过程。这个尤其贴我们想要的 P + 当前 S → 行为选择。
FAtiMA Modular：appraisal 与 affect derivation 分开，emotion 有 intensity 和 decay，personality/cultural bias 可以调制情绪强度，而且模块是可替换的。
甚至 2024 年已经有 LLM game agent 明确走“context/memory → appraisal → emotion memory → behavior”的 Chain-of-Emotion 路线，所以我们更不能拿“LLM + appraisal”本身当创新。

所以真正的 Theory-S 我更倾向：

O / ΔO
  ↓
X: appraisal
  - relevance
  - goal congruence
  - controllability
  - agency/accountability
  - novelty / expectation violation
  ↓
U_k(P, old S, X, Δt)
  ↓
S:
  少量真正持续的行为相关状态
  ↓
π(A | O, P, S)

注意：X 可以丰富，S 不一定要很多。

比如一个 event 可以同时被 appraisal 为：

高度相关
目标受阻
低控制
他人导致
意外

但它最终可能只推动：

tension ↑
engagement ↓
trust_j ↓

这样比现在 confirmed → 1D EMA 像样得多。

O = 宿舍晚上，桌子、床、手机、电脑都可用

→ 今天是认真学 / 敷衍学 / 刷手机 / 先休息

这正是你原来想的东西。

O + Object affordance
→ 生成 A^O（此刻角色知道的合法/可设想动作）

P
→ 稳定 preference prior

S
→ 当前 transient modulation

$$ \text{score}(a) = b(a,O) + g_P(P,a) + g_S(S,a) + g_{PS}(P,S,a) $$

P 是改变了选择偏好，还是偷偷改变了 action support。

同样都能做，这个人平时更倾向什么；在当前状态下又更可能做什么。

固定 W/O/P/A^O
只干预 S
→ π(A) 应发生预期方向且非微小变化

这只是验收系统有表达能力。

真正科研时才问：

现实人物是不是也按照这种 S 变化？

两者完全不同。
