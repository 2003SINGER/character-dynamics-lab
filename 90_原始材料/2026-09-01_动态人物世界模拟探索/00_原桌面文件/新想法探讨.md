## 然后“自然状态更新”我甚至不建议全部 Tick

如果你有 100 万个对象：

```text
每秒：
for object in world:
    object.update(dt)
```

那就很蠢。

很多东西可以直接变成**时间函数**。

例如咖啡：

```yaml
temperature_at_last_update: 80
last_update_time: 10:00
cooling_rate: ...
```

角色 10:20 再看时才计算：

$$
T(10:20)=f(T(10:00),20min)
$$

植物也是：

```text
last_watered = day 3
current_day = day 7
```

需要的时候：

```python
water = calculate_water(last_state, elapsed_time)
```

不必真的模拟：

```text
10:00:01
10:00:02
10:00:03
...
```

而对于真正离散的东西：

```text
12:00 下课
18:30 食堂关闭
23:30 宿舍断电
明天下雨
NPC 8:00 去上课
```

则可以放进：

```text
Event Queue
```

于是世界引擎大概变成：

```text
                 Seed
                  ↓
           World Generator
                  ↓
             Base World
                  ↓
          ┌──── World State ────┐
          │                     │
          │  time dynamics      │
          │  scheduled events   │
          │  random events      │
          │  agent actions      │
          │                     │
          └─────────┬───────────┘
                    ↓
              World State'
```

这就越来越像一个真正的 simulation engine 了。




> 同一人物到了不同世界以后，是否仍然保持合理的人格一致性。

## 评价也先别搞二十个指标

第一阶段我只留三个。

### 1. Next-action prediction

真实剧情：

```text
E1 → E2 → E3 → E4 → E5
```

给到 E4，预测 E5 中角色的真实行为。

看：

$$
P(A_t^*)
$$

或者 rank / NLL。

这个是最硬的，因为有 ground truth。

你原来已经提出过这种 **teacher-forcing 式评价**：每一步预测完，不让自己的预测继续滚动，而是重新喂原著实际发生的事件。这样误差不会滚雪球。

这非常正确。

### 2. Counterfactual sensitivity

只改一个客观变量：

```text
A knows the truth
```

→

```text
A does not know the truth
```

看看：

$$
\Delta W
\rightarrow
\Delta S
\rightarrow
\Delta P(A)

- 什么结果算错？

---

但如果变成：

> 考试失败后 stress 参数应该增加 0.14 还是 0.17？

又太小。

因为即使回答了，对更大的问题没什么意义。

所以最好的粒度通常是：

> **一个明确机制 + 一个明确现象 + 一个明确评价。**

例如你现在：

**机制**

> psychologically constrained state transition

**现象**

> history-dependent character dynamics

**评价**

> behavioral prediction + dynamic coherence

这个大小其实就挺正常。

## 还有一个特别重要的判断标准：能不能被否定

科研问题最好允许出现：

> “我这个想法没用。”

例如你的实验最后发现：

```text
raw history       61.2
summary memory    62.7
LLM state         63.0
psych constrained 61.9
```

那你就必须承认：

> 在这个实验设置下，没有证据表明心理约束状态更新更好。

这叫一个**可证伪的问题**。

反过来：

> 我要做一个更符合人类心理的人物系统。

那几乎永远都能解释成成功：

> “你看，这个角色挺像人的。”

这就太虚。
