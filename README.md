# Character Dynamics Lab｜角色动力学实验室

研究一个可持续运行的**前向角色动力学模型**：角色如何在受限信息下形成自身状态、给出下一行为的条件分布，并让行为反馈改变世界。

> 当前阶段：**机制骨架 v0 已收束；下一阶段是文献驱动的具体计算设计，随后编码最小可回放原型。**
>
> 这不是“已经提出新架构”或“已经验证有效”的声明。文献缺口、状态变量、更新公式、LLM/规则分工和实验结果都仍待核验。

## 课题锚：怎样判断是在深入，还是在漂移

本项目不研究 `W/O/S/P` 四个字母本身，也不以先做完整 NPC、世界模型或人格心理学为目标。第一版持续追问的是：

> **在受限信息下，持续更新的角色状态能否保留历史中对未来行为有用的后果，并据此产生更可检验的行为分布？**

新想法只有直接改善“维护行为相关状态”或“由状态预测/生成行为”时才进入当前主线；否则记录为后续分支。机制变得更具体是深入，不是换题。

### 第二评价维度：效率与可控性（已采纳，不替换课题锚）

在主问题的 Replay、干预和 baseline 比较之外，项目将额外检验一个部署问题：在行为预测质量处于预先规定容差内时，结构化 `O + S` 是否能以更少的上下文、调用、延迟和人工控制成本运行。它不证明状态表示更“心理学正确”，也不可以在预测检验失败时替代主结论。

公平比较必须至少包含 raw history、强 summary baseline 与 Character State；记录 token、LLM 调用次数、P50/P95 决策延迟、单位决策成本、长轨迹吞吐量，以及存档/回放、局部干预、信息权限和调试来源链等可控性指标。

## 现在已经确定什么

```text
W ── SceneFilter / PerceptionFilter ──> O
ΔO + O + 旧 S + P ──语义解释/Appraisal──> X ──字段动力学──> S
O + S + P ──本轮 D──> π(A^char) ──原子结算──> W'
```

- `W`：权威、可执行的故事世界；含对象、身体、剧情事实、时间、affordance 与世界结算。
- `Oᵢ`：角色 i 的局部世界视图；可陈旧、未知或有置信度/来源，不能泄漏 W 的上帝信息。
- `Xᵢ`：角色对新观测变化的结构化意义/Appraisal；它不直接替代状态动力学。
- `Sᵢ`：只属于 i、自身仍会变化且对后续行为有预测价值的 typed fields；各字段拥有自己的更新与时间尺度。
- `Dᵢ`：由 O/S/P 临时计算的决策上下文，决策后不自动留存为 S。
- `Pᵢ`：长期响应参数；主要调制状态的形成、维持和行为表达，而非写死角色动作。

同一前向模型有三种运行方式：叙事回放用真实后续行为检验 `π(A)`；自主模式从 `π(A)` 选择行为；创作模式把候选行为与倾向交给作者参考。

完整、可连续阅读的当前机制见：[完整机制说明 v0](00_研究设计/完整机制说明_v0.md)；接口速查见：[机制骨架 v0](00_研究设计/机制骨架_v0.md)。

## 当前推进顺序

1. **精读机制文献**：按“输入/观察 → 状态 → 更新 → P 的位置 → action 接口”拆 EMA、FAtiMA、BDI、DPC 等，而不是泛读相似 Agent。
2. **定具体计算设计**：选择第一版 S 字段、更新/衰减/巩固规则、P 的参数化、动作接口与可判定实验指标。
3. **编码最小原型**：用户在 `E:\Character Dynamics Demo` 的独立 coding 会话中实现一个连续数天的小房间 Scene、一个角色、有限对象和人物级微行为；保留 replay、干预、日志与消融接口。
4. **用结果收缩机制**：和 raw history、summary、persona 等基线比较；主看预测/校准和干预响应，并以效率—效果与可控性作为第二指标层；无效模块删掉或重写，NPC demo 在闭环稳定后再扩展。

第一版先固定 P，且不把多角色关系演化、完整 Galgame 抽取、开放世界平台或 W/O/S/P 专门模型训练列为前置任务；它们保留为机制有效后的后续分支。
